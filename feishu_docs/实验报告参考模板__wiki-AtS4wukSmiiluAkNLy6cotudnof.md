# 实验报告参考模板

> 修订历史\(Revision History\)
> 
> 

# 实验概述

> 简要说明实验的主要结果，表述实验条件包括输入数据，实验结果作为输出。
> 
> 

# 实验目的

> 我们设计实验是为了回答研发问题。如果无法说明清楚实验目的，请提醒自己很大可能是在浪费自己的时间。即使开始的时候实验目的不明确，只是模模糊糊一个猜想，通过明确写出来，有利于明确自己的思考状态。
> 
> 

# 实验原理

> 知其然更知其所以然。无需长篇大论，给出参考资料的链接亦可。
> 
> 

# 实验环境

> 有利于实验复现，有利于后期撰写报告和论文。
> 
> 

# 实验内容

> 这是同学都会写的内容，建议需要有结构，对应实验目标。
> 
> 

# 实验结果

> 实验结果需要总结，提炼表达结论。
> 
> 

# 思考问题

> 实验过程中有没有遇到问题？
> 
> 

# 经验分享

> 实验结果需要反思并总结经验，包括正面和反面。效果不好的实验结果，也是有价值，说明此路不通。
> 
>
