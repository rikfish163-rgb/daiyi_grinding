# 系统要求与规格说明（中文版）

MATHCOUNTS抢答系统

设备规格书

# 总体描述

系统将由一个中央控制器和六个远程按键盒组成，按键盒通过无线方式或通信线缆（以成本效益最高者为准）连接到控制器。任意时刻将使用2至6个按键盒。该系统用于学术竞赛，以倒计时并显示回答问题的可用时间，并可靠地指示哪位选手先回答问题。当第一位选手按下其按键盒上的按钮时，将触发控制器中的蜂鸣声，并点亮该选手按键盒上的灯。所有其他选手的按钮将被停用。如果时间耗尽，所有选手按钮将被停用，并响起铃声。无论哪种情况，当系统从控制器重置后，按钮将重新激活。

# 设备描述

控制器——控制器应是一个轻便、便携的外壳，处理单元和其他电子器件保护在内。外壳应按需通风，以确保安静、高效和安全地运行。由于控制器需要在不同地点之间移动，组件和安装方式的设计应能承受合理程度的冲击和振动。

控制器中产生声音的组件应能发出三种不同的声音：按下按键时发出两种不同的声音，以及一种表示时间到的声音。

在外壳顶部，将有一个允许操作员将时间限制设置在20至60秒范围内的控制装置、一个启动计时器的按钮、一个重置计时器的按钮、一个操作员可查看的小型数字时间显示，以及一个单独的重置选手按键的按钮。外壳正面将容纳连接蜂鸣器的线缆和连接计时器显示的线缆的连接端口。外壳背面将设置一个开关按钮和电源连接器。

按键盒——按键盒将是小型外壳，顶部有一个按钮和彩色灯。其中三个按键盒将配红灯，另外三个配绿灯。按下按钮时，红灯按键盒发出的声音将与绿灯按键盒不同。每个按键盒的设计应能平放在桌面上，并能承受选手突然、用力地按压按钮，而不会损坏设备或伤害选手。按钮的设计应适合手指按压而非手掌拍击。如果需要，按键盒正面将容纳线缆连接器。

计时器显示——一个两位数数字显示，设计为垂直竖立，使25英尺外的选手可见（高度≥2\.5英寸）。

线缆——如果使用线缆与按键盒和计时器显示通信，则应为LAN类型，两端带易于卡入的连接器，长度为25英尺。电源线应为6英尺长，可包含降压变压器。

# 操作描述

初始设置——将所需数量的按键盒放置在选手桌上，并将控制器放在一张单独的桌子上，该桌子对选手可见且距离在25英尺以内。将按键盒连接到控制器，将控制器连接到电源，然后打开控制器的电源开关。

将计时器控制设置为所需的秒数。操作员只需在比赛开始时执行一次此操作。按下"计时器/蜂鸣器重置"按钮，确保所有按键均处于激活状态。

在选手答题时段开始时，按下"计时开始"按钮。

当第一位选手按下其按键时，该按键盒上的灯将亮起，控制器将产生相应的声音。随后，系统将在时间耗尽前按接收顺序记录所有其他按键，而不触发任何其他灯或声音。

如果该选手回答错误，且比赛规则允许其他选手作答，请按下"下一答案"按钮。这不会重置计时器，计时器将继续倒计时。系统将点亮被记录为下一个按下按键的选手的灯并响起其蜂鸣器，同时停用前一位作答者的蜂鸣器和灯。

根据需要重复此步骤，直到给出正确答案或时间耗尽。

如果给出正确答案，或所有允许作答的选手都已作答，且计时器上仍有剩余时间，请按下"计时器/蜂鸣器重置"按钮。计时器将无声地恢复到预先选定的值，并等待为下一题启动。按下此按钮还将重置所有抢答器。

如果在给出正确答案或所有选手作答完毕之前时间耗尽，控制器将发出相应的声音，所有按键将被停用。按下计时器重置按钮即可为下一题做好准备。
