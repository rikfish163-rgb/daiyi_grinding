# 如何合作撰写学术论文

撰写学术论文是个技能提升的过程，建议多读多练。为了有效撰写学术论文，建议采取下面写作路径，将撰写论文的大型复杂而有挑战性的工作拆解成更小规模的序列任务，有利于推动论文写作工作进展。

1. 建议参考[“论文标题”自问自答参考模板](“论文标题”答辩自问自答参考模板__wiki-UQZEwJGh8iwXYVkYbq7cafJcn3c.md)，梳理论文想法和科研故事；

2. 建议参考[论文写作大纲思维导图](论文写作大纲思维导图参考样例__wiki-PNYNwt8EOiGtwrkSFRycMApLn13.md)，撰写论文大纲；

3. 在飞书撰写中文版本，汇集大家的智慧；

4. 建议参考[如何使用Overleaf在线协作编译Latex论文？](https://hustdian.feishu.cn/wiki/Lafvwl3Cnifwn8kQYfwcyt3wnze?from=from_copylink)，在Overleaf网站\(http://www\.overleaf\.com\)创建论文版本，合作撰写论文，有效协作；

5. 参考[如何从数据库导出论文BibTex条目？](https://hustdian.feishu.cn/wiki/VxuzwRIQzi5FatkRpkXcbVaancb?from=from_copylink)，编写BibTex条目：第一作者的姓\+年份\+发表场所\+其他有助于记忆标签，便于同步文献。标注年份，体现文献的时效性；标注发表场所，体现文献的权威性。

6. 使用Gemini/ChatGPT/DeepSeek等工具进行文字润色，迭代修改论文。注意AI工具使用规范，参考[电气学院毕业设计AIGC使用指导意见](https://hustdian.feishu.cn/wiki/YfMmwzMLqiZWeokDiIxcfCdwngf?from=from_copylink)。
