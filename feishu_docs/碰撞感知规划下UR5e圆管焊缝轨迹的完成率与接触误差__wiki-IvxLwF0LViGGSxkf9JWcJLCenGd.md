# 实验原理

本实验的软件链路为：**合成点云 → 焊缝中心线提取 → 砂轮接触几何建模 → 路径生成 → 逆运动学与碰撞感知笛卡尔规划 → 正运动学误差回算 → RViz 可视化**。各环节原理如下。

## 焊缝中心线提取

输入为合成圆管焊缝点云（11608 个点）。算法从点云中识别凸起的焊缝区域，并将其几何形态提取为一条中心线，作为后续打磨路径沿缝进给段的基准。中心线在 RViz 中以红色线显示。

## 砂轮接触几何

打磨路径的生成必须考虑砂轮尺寸与工具坐标系的偏置关系：砂轮模型半径为 55 mm，演示中设定 `tool0` 到砂轮中心的偏置为 70 mm。据此把中心线转换为砂轮与工件表面接触的位置点，并生成三段式路径：接近段（从安全位置接近工件）、沿缝进给段（沿焊缝中心线匀速进给）、抬刀段（打磨完成后抬离工件）。

## 逆运动学与碰撞感知笛卡尔路径规划

路径点以笛卡尔空间坐标给出，需经 MoveIt 做逆运动学（IK）求解为关节空间轨迹，并在规划时进行碰撞检测。碰撞检查覆盖机械臂本体、圆管、工作台和支座等场景几何；每次 IK 和碰撞规划会选取不同的有效关节分支，因此规划点数量与最近采样误差会有小幅变化，验收以当次终端输出为准。规划结果通过笛卡尔路径完成率（门槛 99%）和轨迹采样接触误差（门槛 5 mm）两项指标校验。

## 正运动学误差回算

规划轨迹的接触误差并非直接测量获得，而是将规划轨迹按离散采样点经正运动学（FK）回算到各采样点的机械臂末端位姿，再计算其与工件表面/焊缝的最短距离，用于校验轨迹是否贴合焊缝。该误差代表离散采样点的最近距离，不能代表连续运动的最大误差或实测接触误差。

# 经验分享

## 正面经验

- **合成数据快速闭环验证**：用生成器构造确定性的圆管焊缝点云，能在不依赖真实工件和相机的条件下先行验证"点云到轨迹"的算法与软件流程，迭代速度快、问题可复现，是打磨轨迹规划上真机前的合理第一步。

- **模块化文件组织清晰**：启动脚本、核心算法、点云生成器、场景可视化、碰撞几何、RViz 配置分工明确（`run_*.ps1`、`*_demo.py`、`scene_and_path.py`、`grinding_view.rviz`），便于单独调试与替换实现。

- **FK 回算校验思路实用**：在没有力传感器和实测接触的条件下，用正运动学回算采样点与工件的最近距离作为接触误差的近似，能在流程早期暴露路径偏离问题，成本低、见效快。

- **可视化要素设计到位**：中心线、接触点、法向、力方向用不同颜色区分，轨迹用降透明度抽样预览，配合默认相机视角，使各环节结果一目了然。

## 反面经验与改进方向

- **合成数据与真实数据存在鸿沟**：实测点云带噪声、离群点、残缺与位姿不确定，合成数据验证通过不代表真实工件可用，必须尽早引入实测数据与相机外参标定。

- **砂轮未参与碰撞建模**：砂轮只是可视模型，规划轨迹可能在真实作业中发生砂轮与工件/支座的干涉，应把砂轮几何加入 MoveIt 碰撞检测。

- **力标记不等于力控**：`15 N` 仅用于显示，缺少力传感器、恒力控制与接触力动力学，真实磨削的去除效果无法保证，需在后续引入力控闭环。

- **误差指标口径有限**：离散采样 FK 回算的最近距离无法代表连续运动最大误差或实测接触误差，验收时应补充连续轨迹误差与实测对照。

- **物理效应缺失**：无砂轮转动、磨屑、材料去除率与工件表面变化模型，规划结果只能指导轨迹形态，不能指导工艺参数（转速、进给、压力）选择。
