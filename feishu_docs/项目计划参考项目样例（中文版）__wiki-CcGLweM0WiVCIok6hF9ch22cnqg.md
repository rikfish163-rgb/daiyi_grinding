# 执行摘要

MATHCOUNTS是一项面向热爱数学和问题解决的中学生的全国性竞赛系列。在决赛回合中，2至6名学生会面对一道题目，并有20至60秒的时间作答。第一个抢答的学生作答，根据规则，要么允许第二个抢答的学生回答，要么让其余学生获得再次抢答的机会。只有第一个被按下的抢答器才会触发灯光和声音。比赛操作员坐在中央控制台旁，所有其他按钮单元都通过线路连接到中央控制台。操作员可以让在当前抢答者之后按下按钮的按钮单元亮起、重置按钮单元、切换操作模式以及管理计时器（中央控制台自带一个小计时器，另有一个较大的计时器面向参赛选手，两者保持相同时间）。操作员通过启动、重置或更改显示时长来完成上述操作（只要计时器当前不在倒计时中）。几十年来，Rose\-Hulman本校一直使用同一套抢答系统，而该系统目前依赖一台极其过时的计算机。加之系统多年运行已严重磨损，人们担心它可能很快失效。因此，我们的目标是在保留现有系统基本功能的同时，对其进行现代化改造，使其更耐用、更易用。

重新设计的系统预期至少可使用10年，将使用Arduino微控制器，连接6个按钮单元、2个计时器显示屏以及中央控制台上的一组按钮输入。将采用I2C通信以减少引脚占用，以太网线缆则提供组件之间的耐用连接。该设备工作电压为5V，通过标准120VAC墙壁插座供电；定制PCB将确保设计稳健，并提供易于插拔设备的端口。系统将通过控制器上的一个开关设置两种模式：类型1模式（重置抢答盒）和类型2模式（下一位作答）。在类型1模式下，当某位选手第一个按下按钮时，操作员将重置所有抢答器；如果回答错误，任何选手都可以再次抢答并给出不同答案。在类型2模式下，系统会记住所有按钮被按下的顺序，因此当某位选手答错时，操作员可以按下"下一答案"按钮，切换到下一位抢答的选手。这两个功能由同一个物理按钮操作，但通过拨动"切换模式"开关来改变其效果。在两种模式下，计时器都不会因选手抢答而停止。此外，通过使用"计时增加"和"计时减少"按钮，可以以5秒为增量改变计时器运行的时间长度，范围为20秒至60秒。
