# 智能视觉引导打磨仿真技术提升对照表



整理日期：2026\-10\-12。下表将前四阶段作为一个整体汇报，不按版本分别展开。



## 1\. 技术提升总表



|技术模块|解决的问题|采用的方法|形成的结果|当前边界|
|---|---|---|---|---|
|点云输入|规划不能只依赖手工示例表面|接入公开 PCL `table_scene_lms400.pcd`，完成滤波、RANSAC 平面提取和 ROI 选择|获得可用于规划的扫描区域、点云预览和来源报告|公开数据是桌面场景，不是工业毛刺数据|
|表面重建|平面近似无法表达局部起伏|局部 MLS 拟合、平滑高度场、三角网格重建|生成带高度变化的局部工件表面|适用于局部单值表面，不能表示倒扣和多层遮挡|
|法向估计|固定工具姿态不能随形加工|根据高度场梯度计算表面法向，并建立稳定切向参考|工具姿态可随局部表面变化|法向质量依赖扫描密度、噪声和重建质量|
|砂轮几何补偿|表面点不是 `tool0` 位置，工具偏置会造成误差|将轮缘局部偏置和 8 mm 名义间隙纳入位姿计算|得到轮缘位置对应的六轴工具目标|8 mm 是预接触仿真间隙，不是真实打磨接触量|
|路径规划|需要把加工区域组织成机器人可走的路径|使用 Noether 生成往复/栅格路径，再通过 MoveIt 进行笛卡尔规划|输出路径位姿、关节状态和 RViz 回放|当前仍是仿真回放，不连接真实机器人|
|六轴逆解|笛卡尔位姿不一定可由机械臂到达|UR5e URDF、MoveIt 逆解和轨迹状态检查|形成六轴关节轨迹|仅验证当前机器人模型和虚拟摆放|
|运动学核查|轨迹可能接近关节极限或奇异姿态|URDF 关节限位、独立 FK、Jacobian 奇异值筛查|输出限位裕量、FK 差异和奇异性报告|阈值属于仿真门槛，不等于实机安全认证|
|碰撞验证|只检查路径端点可能漏掉中间碰撞|机器人、砂轮、主轴、工件闭合网格；中点及自适应插值采样|输出碰撞通过/失败和采样数量|离散采样不是连续扫掠体安全证明|
|时间参数化|几何路径没有速度、加速度和 jerk 约束|分段五次插值和解析上限检查|形成带时间信息的仿真轨迹|尚未完成工业控制器的实时约束验证|
|缺陷接口|后续毛刺识别接入容易破坏规划接口|预留 `burr-defect/v1`，包含坐标系、时间、类型、置信度、中心、法向、尺寸和高度|识别模型可按固定 JSON 契约接入|当前接口是预留，未接真实毛刺模型|
|可视化与审计|仅看动画难以复核输入和结果|RViz 显示点云、工件、砂轮、路径和机器人；网页保存报告来源|形成可回放、可检查的实验记录|网页报告不是 ROS 实时安全监控|



## 2\. 使用的开源框架与作用



|开源框架/项目|在本系统中的作用|本项目实际使用方式|来源/说明|
|---|---|---|---|
|ROS 2 Humble|机器人仿真节点、消息、TF 和进程通信|在 Docker 容器中运行 ROS 2 节点，按不同 ROS domain 隔离演示|https://docs\.ros\.org/en/humble/；开源机器人中间件|
|MoveIt 2|UR5e 逆运动学、笛卡尔路径和碰撞规划|调用 MoveIt 服务生成轨迹，并对返回状态做二次核查|https://moveit\.picknik\.ai/；开源机器人运动规划框架|
|Noether|表面切片、栅格/往复加工路径生成|通过 `/plan_tool_path` 服务生成表面加工段，不是手写固定轨迹|https://github\.com/ros\-industrial/noether；ROS\-Industrial 开源路径规划项目|
|RViz 2|六轴机器人、工件、砂轮、点云和路径可视化|加载自定义 `.rviz` 配置，显示 ROS 话题和 RobotModel|ROS 2 官方可视化工具，随 ROS 2 使用|
|PCL 数据仓库|提供公开扫描点云样例|使用 `table_scene_lms400.pcd` 作为点云输入和流程验证数据|https://github\.com/PointCloudLibrary/data/blob/master/tutorials/table\_scene\_lms400\.pcd；仓库保留 BSD 许可说明|
|PCL 格式/点云处理思路|点云数据组织与处理参考|本项目具体滤波、RANSAC 和支持域计算主要由 NumPy/SciPy 脚本实现|不应表述为完整调用 PCL C\+\+ 算法库|
|NumPy|高度场、坐标、法向、轨迹和验证计算|在 ROS 容器及离线运行时中用于数组和数值运算|https://numpy\.org/；开源数值计算库|
|SciPy|点云邻域、平滑和科学计算支持|容器中用于点云处理；提供 NumPy 后备实现|https://scipy\.org/；开源科学计算库|
|URDF / `robot_state_publisher`|机器人结构、关节和 TF 发布|使用 UR5e URDF 检查关节限位并驱动 RViz 模型显示|ROS 2 开源机器人描述与 TF 工具|
|Docker Desktop / Docker Engine|固定 ROS 2、MoveIt 和 Noether 环境|Windows 主机通过容器运行 Linux ROS 仿真|https://www\.docker\.com/；运行环境工具，不是规划算法|

## 4\. 汇报结论与后续接入



当前仿真已经建立“点云输入—表面建模—工具姿态—六轴轨迹—碰撞/运动学验证—可视化审计”的技术骨架。开源框架承担通用能力，项目自有代码主要负责点云到工艺几何的适配、砂轮偏置、验证门禁和接口组织。



要形成工业打磨系统，还需要接入企业真实工件点云或 CAD、机器人 URDF 和控制器资料、手眼与 TCP 标定、真实毛刺标注数据、力/扭矩传感器以及工艺参数。当前仿真不包含真实接触和材料去除。
