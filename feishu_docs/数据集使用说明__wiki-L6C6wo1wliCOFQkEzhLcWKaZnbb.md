# 数据集使用说明

使用的是 **Real3D\-AD 三维点云异常检测数据集**，相关论文发表于 **NeurIPS 2023 的 Datasets and Benchmarks 赛道**。它主要用于研究“根据正常工件形状，判断待测工件哪里存在几何异常。

使用 \.txt，是因为它同时包含点云坐标和**缺陷标签**，便于直接确定需要生成轨迹的区域。

当前使用的 Real3D\-AD gt/\*\.txt 文件，每行对应一个点：

```Plain Text
X坐标    Y坐标    Z坐标    缺陷标签
115.12   -2.24    222.82   1
```

前三列描述工件几何，第四列中 0 表示正常点、1 表示异常点。当前仿真读取这些异常点作为目标区域，再生成候选打磨路径。
