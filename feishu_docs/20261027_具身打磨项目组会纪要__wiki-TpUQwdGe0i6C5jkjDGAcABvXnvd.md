# 二、讨论议题

## 2\.1 项目内外沟通划分与甲方交流方法（宋建建指导）

- **会议分两部分**：内部会议谈"怎么做"——算法、软件、硬件、数学方法、专利与文章产出等；对外会议只谈输入与输出。

- **黑箱逻辑**：客户关心的是输入（我们需要客户提供什么，如各种带毛边的铸件样本）和输出（毛边打磨结果）；中间技术过程客户知道得越少越好——客户正因为不知道怎么做才需要我们。

- **客户关心的三件事**：①技术指标能否达到；②需要提供什么设备、花多少钱；③项目时间节点（什么时候完成什么）。

- **层层定义输入输出**：整个项目、每个环节、每个学生自己的"小黑箱"都要把输入输出定义清楚，互相连接成系统。
