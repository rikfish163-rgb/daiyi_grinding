## 吴玥：六关节运动模型搭建与 38 点路径接入验证

**本周五项工作**：

1. 将公司数字模型导入仿真；

2. 检查运动关系与碰撞外形；

3. 将末端目标转换为关节角；

4. 用已有 38 点路径做小范围接入；

5. 准备真实点云接入与稀疏化复测。

**模型构建**（STEP 文件→可运动可检查模型）：

- 先恢复各零件装配位置，统一尺寸单位为米；

- 根据相邻零件上共轴的圆柱面找出 6 个关节转轴；

- 装配中表示活动范围的包络体并非实际零件，单独保留；

- 逐个转动关节检查连杆联动关系，将独立计算的位置朝向与 ROS2 实际发布数据对照；

- 辅助伸缩机构按两端铰点计算转动与伸缩，实际允许行程待确认。

**验证结果**：原 CAD 姿态与组合角度下的外形几乎一致；逆解功能已在模型中验证（同一目标可能有多种关节组合，需逐一检查碰撞）；模型角度与实际角度的对应关系还需进一步核对。

**38 点路径接入**：路径法向用于确定工具接近表面的方向；因实际工具安装参数未确认，暂在仿真中固定工件位置，将工具工作点 TCP 暂定在法兰参考系 X 方向 150 毫米处（属实验假设，待砂轮安装标定后核对）。对每个路径点求逆解并优先选择接近上一点的关节构型，相邻关节角间插值增加 116 个内部样点，得到 38 端点 \+ 116 样点共 **154 个姿态**。

**核对数据**：38 个路径点逆解与正解回代全部通过；相邻路径点最大单轴角度变化约 **4\.914°**；154 个姿态的原生碰撞查询与独立计算一致，未报告碰撞盒重叠；ROS2 实际发布的 154 组连杆变换及辅助机构碰撞数据均与预期一致。

**关键偏差**：关节插值时 TCP 偏离目标直线，已检查样点中最大值约 **0\.179 毫米**；部分内部样点也偏离相邻目标点之间的直线。结论是已有路径可以转化为当前模型的关节姿态并完成有限采样的碰撞核对，但**上周名义表面路径的高度误差与覆盖结果，不能直接等同于机械臂执行结果**。

**当前局限**：采用仿真摆放与虚拟 TCP，碰撞检查尚未包含实际工具、工件、线缆与周围设备，也未通过轨迹控制器执行完整运动。

**下周计划**：①路径段完整检查——研究如何保持工具沿目标路径、进出路径、检查构形连续性与运动过程中的碰撞；②核对模型与实际——虽有各轴范围和速度资料，仍需确认零位、正方向、法兰坐标与实际工件 TCP 后再应用限位；③真实点云到位后接回原实验——对同一区域比较完整点云与稀疏点云生成的路径，并用独立测量确定表面及根部参照。

## 薛力源：3D\-ADAM 工业三维异常检测数据集论文分享

**背景**：上周参观东风工厂真实生产环境与具体工件，萌生寻找与真实工业场景高度相似的数据集或数据处理方法的思路；经检索找到 ICRA 2026 收录的 3D\-ADAM 工业三维异常检测数据集论文。

**论文动机**：现有三维异常检测数据集工业缺陷类型少、覆盖物体与缺陷类别有限，无法反映真实生产环境中复杂的机械结构、光照变化、工件姿态与遮挡问题，难以适配工业需求；论文因此构建更贴近真实场景的大规模数据集，为算法迭代与模型测试提供可靠数据来源与评价基准。

**现有数据集四类不足**：缺陷类型和机械结构有限；缺陷类别较少；工业代表性不足（缺少工业生产工件特征）；泛化性较弱。

**数据集构建**：用 FDM 3D 打印制造正常与缺陷零件并拼装机械臂；利用四种工业深度传感器进行多视角图像与点云采集；标注 12 类缺陷与 16 类机械结构。

**与项目需求的匹配**：数据集中的凸起、毛刺、粗糙等缺陷类型，与企业方提出的铸件飞边、毛刺、浇口残根具有几何相似性，可作为算法研究参考；其数据采集方法也可为自建数据集提供借鉴。

**论文实验**：采用无监督异常检测方案——正常样本训练、异常样本按 6:4 划分为测试集与验证集；两类测试为模型基准测试（异常检测与分割性能）与工业专家验证（邀请专家标注匹配缺陷并与原始标注比对）。

**实验结果**：现有模型对缺陷的精确分割表现欠佳——pixel AUROC（区分正常与异常像素）尚可，但 AUPro（缺陷定位与分割覆盖）较差、提升空间明显；专家重标注与原始标注比对 IOU 为 0\.6、PL 为 0\.76，标注一致性较好，数据集可靠性得到验证。

**对本项目的启发**：

1. 缺陷几何相似性可作算法研究参考；

2. 数据采集方法可借鉴；

3. 针对百万级点云处理与细小缺陷识别需求，可先用该数据集做降采样测试，检验不同检测方法对几何细节与精度的影响；

4. 追溯引用该数据集的相关论文，寻找更适配工业场景的检测方案（作为下一阶段任务）。

## 孔凌峰：工作站环境配置与 PointNet\+\+/PTV3 试训练

**本周任务**：配置工作站训练环境；基于上周分享论文（陶瓷封装基板表面缺陷分割任务及数据集），在工作站上试训练 PointNet\+\+ 与 PTV3（Point Transformer V3），评估训练开销，探索真实工件点云训练所需调整方向。

|环境|显存|内存|
|---|---|---|
|本地 PC|8G|24G|
|工作站|RTX A5000，24G|128G|

两组实验共用相同数据集、点云坐标输入规则、分块与训练分组方案，仅点云设置、batch size 与预算略有差异。

|\#|配置|结果|资源|
|---|---|---|---|
|①|本机 PointNet\+\+，640 步，batch 8|准确率与召回率很低|显存占用低|
|②|预算扩至 6400 步|准确率上升|—|
|③|扩大 batch size|准确率变化不大、稍有提升|显存占用翻倍|
|④|工作站 batch 128|准确率仍低；修正训练完成后的评估顺序后升至 **30%**，F1 与召回率同步上升|显存 14G，1 小时以上|
|⑤|低学习率微调|性能小幅提升|—|
|⑥|PTV3，缩步数至 3200 步|综合准确率最高|显存 19G，2\.5 小时|

**实验分析**：本机 640 步因预算与 batch size 小、样本曝光不足，不足以充分学习；6400 步已出现过拟合，最优效果约出现在 **3000—4000 步**（之后 loss 继续降低但 AP 不升）；PTV3 略强于 PointNet\+\+；低学习率微调可小幅提升准确率。**当前准确率整体偏低**，点云处理方式、网络结构与训练配置仍需大量优化。

**下一步训练考虑**：真实工件点云可能达百万数量级，远大于论文数据集中单个点云规模（论文全数据集点云总数约 1\.8 亿点），需结合工件点云规模调整**分块尺寸与训练覆盖方式**，保留飞边、毛刺等缺陷信息；分块时一个块要同时包含飞边根部和附近正常本体，帮助模型判断哪些结构应去除。3D 相机到位后扫描真实工件，统计点数、局部点间距、重复点与缺失点，人工确认最小飞边及根部是否被实际扫描到；随后建立工件整件检测基线并补充工件级评价——跑通分块预测还原流程、检查全部有效点覆盖、记录每件耗时，并加入飞边区域召回率、漏检误报区域数、根部定位误差等指标。

## 王释钰：军山校区具身打磨场 ROS 仿真与运动规划系统

**本周两项工作**：①参考军山校区具身打磨场实验场地设计及企业方提供的机械臂资料，在 ROS 中完成仿真场景搭建，支撑后续安全验证；②搭建“指定加工区域生成路径”的机械臂运动规划系统。

**系统流程**：

1. 网页端选择工件；

2. 上传标注好加工区域的 3D CAD 数据集文件（系统目前无目标检测，直接使用已标注区域的数据集）；

3. 读取加工区域并生成路径；

4. 碰撞检查与轨迹修正；

5. 在 RViz 中回放轨迹，失败的规划给出相应解释。

**轨迹修正方法**：更换模具候选、切换尝试法向方向等。

**当前问题**：部分姿态达不到、机械臂会碰撞（与缺少前端夹具资料有关）；计算时间较长、易失败；自动修正模块成功率低，**十多段轨迹仅能修正通过约 1 段**；轨迹生成步骤较冗余。

**下一步**：优化自动修正模块；精简轨迹生成步骤、缩短生成时间；补充完整打磨工具 CAD 文件（转换器圆盘与铣刀、钢刷、磨砂轮三个工具）并加入仿真系统，以获取更精确的仿真数据。

# 存在问题与挑战

|问题|说明|
|---|---|
|机械臂仿真精度受限|碰撞检查未覆盖实际工具、工件、线缆与周围设备；工具安装参数未确认、TCP 为仿真假设；关节插值使 TCP 偏离原目标直线（最大约 0\.179 毫米），名义路径结果不能等同机械臂执行结果（吴玥）|
|模型与实际对应关系待核对|各轴范围、速度资料已有，但零位、正方向、法兰坐标、实际工件 TCP 与限位仍需确认后才能正确应用；辅助伸缩机构实际行程未确认（吴玥）|
|现有数据集工业代表性不足|现有三维异常检测数据集缺陷类型、机械结构有限，工业代表性弱、泛化性差，难以满足真实工业场景需求（薛力源）|
|点云训练准确率整体偏低|训练配置与点云处理方式仍需大量优化：步数不足样本曝光不够、步数过多过拟合，直接沿用论文小工件分块方法不合理；真实工件点云规模大（可达百万级），需重新设计分块（孔凌峰）|
|仿真系统修正成功率低|轨迹自动修正成功率低（十多段仅约 1 段通过）、计算耗时长、步骤冗余；部分姿态因缺完整工具模型资料无法验证（王释钰）|
|企业资料缺口|缺机械臂前端转换器与铣刀、打磨轮、钢刷的 CAD 文件，影响仿真精度与验证；AI 生成代码与仿真可能含错误，需要企业提供测试用例核验|
|AI 生成内容风险|AI 生成的报告文本、仿真代码与图表可能存在错误，必须人工校验后使用；文献引用信息不全、缺少参考性（黑晓军）|
|对外汇报信息传达效率|汇报中英文指标（Accuracy、Recall 等）对非机器学习人员不友好；内容重点不突出、篇幅过长，需精简并将核心结论前置（黑晓军）|

# 讨论的技术路线

## 机械臂模型仿真与路径验证

1. 企业 CAD（STEP 文件）→ 恢复装配关系、统一单位；

2. 提取关节转轴（共轴圆柱面）→ 六关节可运动可检查模型；

3. 正运动学与逆解验证；

4. 38 点旧路径接入（逆解＋插值采样＋碰撞查询）；

5. 保持工具沿目标路径的路径段完整检查；

6. 模型参数与实际设备核对（零位／正方向／TCP／限位）；

7. 真实点云接入复测（完整与稀疏点云同区域对比）。

## 工业异常检测数据与算法

1. 以 3D\-ADAM 等贴近真实工业场景的大规模数据集为基准；

2. 借鉴其 FDM 3D 打印造件与多工业深度传感器多视角采集方法；

3. 结合自有工件点云做降采样测试，评估对几何细节与检测精度的影响；

4. 追溯引用该数据集的相关论文，寻找更适配方案；

5. 自建面向飞边、毛刺、浇口残根的真实工件数据集。

## 点云缺陷检测训练

1. PointNet\+\+／PTV3 基线试训练，调步数、batch size、学习率与评估顺序，最优步数约 3000—4000；

2. 针对百万级工件点云重设分块尺寸与训练覆盖方式，分块同时包含飞边根部与正常本体；

3. 3D 相机到位后扫描真实工件、统计点云参数；
