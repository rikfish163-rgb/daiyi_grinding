# 视觉检测技术路线分析

# 论文技术路线适用场景

来源[具身打磨项目调研报告](具身打磨项目调研报告__wiki-Z2gXwydnNi4FbVkhDLochw4QnSO.md)

## 论文1 Automated 3D Burr Detection in Cast Manufacturing using Sparse Convolutional Neural Networks

适用场景：工件 CAD 已知，但实物扫描与 CAD 难以可靠对齐。

文章主要提出一种基于 Sparse CNN 的毛刺检测方法，核心在于使用稀疏残差 U\-Net 学习 DPFH 描述子，通过特征匹配和 RANSAC 得到质量更高的配准，然后使用几何方法后处理识别毛刺。

数据需求：工件CAD（或生成的点云），分型面或可能出现毛刺的区域，真实工件扫描数据，现实中毛刺真实尺寸。

预估算力开销：按37\.85M参数计算，FP32权重约151 MB；若采用普通 FP32 Adam，权重、梯度和两个动量状态合计约606 MB

## 论文2 Towards Scalable 3D Anomaly Detection and Localization

适用场景：真实异常样本少、标注成本高，而且异常形态难以穷举。

文章提出的 IMRNet 在训练时遮挡正常点云的一部分，让网络恢复缺失部分，测试时反复遮挡、重建待检测物体，尝试把异常结构恢复成正常结构，然后比较输入与重建结果的几何和特征差异，输出异常位置和分数。文章还提出了合成异常数据集的方法Anomaly\-ShapeNet。

数据需求：ShapeNet\-55（ShapeNetCore），Anomaly\-ShapeNet，Real3D\-AD，真实工件（合格件，异常件）扫描。

预估算例开销：文章没有可供评估的数据。

## 文献3 Flash Extraction and Grinding Path Fitting Based on Point Cloud of Casting Parts

（该文章为企业“中易铸造”的文章，非正式论文）

适用场景：建立一个标准模型比较＋几何路径生成的基线。

文章描述了点云体素下采样、RANSAC与ICP配准、最近邻求差、局部平面距离测量，以及二维轮廓提取和三次样条拟合的方法。

数据需求：合格件CAD/点云，待加工件点云。

预估算例开销：无需训练。

# 技术路线候选

1. 三维监督分割＋几何测量

流程：待加工件扫描\-\>AI分割批缝毛刺\-\>结合参考形状确定根部\-\>原始点云测量尺寸\-\>输出轨迹规划需要的数据

模型可考虑从PointNet\+\+ 基线起步，然后考虑Point Transformer V3等更强大的网络。

需要含标注的数据集，标注包含工件本体，批缝/毛刺/飞边，环境背景，表面类别（如果不同表面对刀具姿态有不同要求），根部和边界。

2. 正常样本异常检测＋局部量测

采用 M3DM 这类正常特征库方法：学习合格工件的 RGB 和三维特征，检测偏离正常分布的区域。

流程：正常件建立特征库 → 新工件异常定位 → 判断是否属于可打磨的材料凸出 → 局部测量 → 输出轨迹规划需要的数据

需要特别定义正常的信息：正常样本应覆盖允许的铸造尺寸变化和表面粗糙度；扫描缺失、油污、划痕和反光可能产生异常响应；异常可能是凸起，也可能是凹陷或缺料，需要后续分类和几何判断。

3. AI 配准＋参考模型比对

在有准确 CAD 或合格件的点云的前提下，利用AI精细配准。在参考模型可靠时，可以减少逐点毛刺标注，把 AI 能力集中在模型对齐上。

流程：AI 提取与匹配几何特征 → 粗配准 → 本体区域精配准 → 计算超出参考模型表面的材料 → 提取毛刺与路径 → 输出轨迹规划需要的数据
