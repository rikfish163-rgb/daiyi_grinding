# 飞书会议演示模式操作指南

本文面向需要在飞书会议中演示课件、汇报材料或文档的 Dian 团队成员，介绍在会议中进入「演示模式」的完整操作方法：包括两种演示路径（妙享投文档、共享屏幕/窗口）、两种幻灯片演示模式（普通演示、演示者模式）、演示过程中的实用工具，以及常见问题与注意事项。

# 一、了解演示模式

「在飞书会议中使用演示模式」包含两个环节：先在会议中把内容共享给参会人，再以演示的方式播放幻灯片或文档。飞书提供了两条路径：

|演示路径|适用场景|特点|
|---|---|---|
|妙享（投文档）|演示飞书幻灯片、文档、表格，或本地 Word / Excel / PowerPoint / PDF|画面清晰；参会人可「跟随共享人」或「自由浏览」；不受其他软件弹窗影响|
|共享屏幕 / 窗口|演示本地 PPT、Keynote 等任意应用或整个桌面|所见即所得；可搭配开启妙享模式、标注、远程控制|

使用飞书幻灯片演示时，还可在两种演示模式间选择：

- **普通演示模式**：演示者和观众使用同一个视图，适合大多数线上讲课、汇报场景。

- **演示者模式**：同时打开「观众视图」和「演示者视图」。演示者视图仅供自己查看，包含演讲者备注、计时器等，适合需要看稿讲解的场景。

# 二、开始前的准备

1. **安装飞书客户端**：建议使用最新版飞书桌面端（妙享模式要求飞书客户端 V6\.0 及以上版本）。

2. **准备演示文件**：若是飞书幻灯片，请确认文件已保存在云文档中且你拥有访问权限；若是本地文件，确认可正常打开。

3. **检查网络与设备**：确认摄像头、麦克风正常，网络稳定，以免演示中断。

4. **建议提前静音**：演示前将即时通讯软件设为免打扰，避免弹窗消息在共享画面中暴露隐私。

# 三、路径一：通过妙享演示飞书幻灯片（推荐）

## 1\. 发起或加入会议

在飞书桌面端点击左侧「视频会议」，发起会议或加入已有会议。

## 2\. 发起妙享（投文档）

1. 点击会议底部工具栏的 **共享** 按钮。

2. 在弹窗中选择 **投文档** 页面。

3. 选择要演示的内容：

    - 共享已有文档：搜索或选择已储存在云文档中的幻灯片、文档、表格；

    - 共享本地文件：点击「新建/上传 \> 上传文件」，上传本地 Word、Excel、PowerPoint 或 PDF。

**可观察结果**：所有参会人会在会议窗口中看到正在妙享的内容，共享人界面出现「你正在共享」状态栏。

## 3\. 进入演示模式播放幻灯片

1. 在共享画面中打开目标幻灯片文件。

2. 点击幻灯片右上角的 **演示** 按钮，即可**从当前页开始**演示；也可点击「演示」旁的下拉菜单选择「从头开始」。

3. 快捷键：Windows 使用 **Ctrl \+ Enter**（当前页开始）、**Ctrl \+ Shift \+ Enter**（从头开始）；Mac 对应 **Command \+ Enter**、**Command \+ Shift \+ Enter**。

妙享模式下共享人切换窗口或最小化窗口，参会人仍可继续浏览该文档，不会打断演示。

## 4\. 演示中的常用操作

- **切换页面**：使用键盘方向键，或移动鼠标到幻灯片左下角的浮动工具栏，点击上一页 / 下一页。

- **使用激光笔**：在浮动工具栏中选择「激光笔」，移动鼠标即可指向重点内容。

- **同步最新内容**：编辑后点击「同步最新内容」，让演示画面更新到最新版本。

- **右键菜单**：右键点击演示页面，也可使用以上辅助功能，包括「退出演示」。

## 5\. 参会人视角：跟随与自由浏览

- 默认情况下，所有参会人**跟随共享人**的浏览节奏，与演示进度保持同步。

- 参会人**双击或滚动鼠标**即可进入「自由浏览」，按自己的节奏查看文档；点击「跟随共享人」可重新回到共享人位置。

- 若参会人拥有该文档的编辑权限，还可在自由浏览时实时编辑，编辑过程对所有人可见。

# 四、路径二：通过共享屏幕/窗口演示本地 PPT

## 1\. 发起共享

1. 点击会议底部工具栏的 **共享** 按钮。

2. 在弹窗中选择 **桌面与窗口** 页面。

3. 选择需要共享的**桌面**或**应用窗口**，点击「共享」。

4. 如需同步声音，勾选「共享电脑音频」；如需优先保证流畅度，勾选「视频流畅度优先」。

## 2\. 打开并播放本地 PPT

1. 在共享的窗口或桌面中打开本地 PPT 文件，进入放映模式。

2. 使用键盘方向键或翻页工具切换页面，进行讲解。

## 3\. 共享工具栏的进阶操作

- **暂停共享**：需要处理其他事务时，点击共享工具栏中的「暂停共享」，避免个人信息泄露；共享窗口被最小化时，共享也会自动暂停。

- **妙享模式**：共享画面中出现飞书文档时，可开启妙享模式，让参会人自由浏览该文档（支持云文档、表格、多维表格、思维笔记等）。

- **标注**：点击「标注」按钮选择工具，在共享画面上圈画重点；参会人也可点击上方的「开始标注」参与标注。

# 五、使用演示者模式（看稿讲解）

1. 打开飞书幻灯片，点击右上角「演示」旁的下拉菜单，选择 **演示者视图**。

2. 系统自动打开一个**观众视图窗口**：把它拖动到要共享的位置（例如拖到共享画面中），点击「进入全屏」。

3. 原页面变为**演示者视图**：仅自己可见，包含演讲者备注、播放计时器、幻灯片导航栏。

4. 演示者模式下可直接在演示者视图中使用上一页 / 下一页、激光笔、同步最新内容、计时器等工具。

演示者模式仅支持从当前页面开始演示，且建议连接扩展屏后使用，否则演示者视图可能被中断。

# 六、两种演示路径怎么选

|对比项|妙享（投文档）|共享屏幕 / 窗口|
|---|---|---|
|演示对象|飞书幻灯片、文档、表格及本地 Office / PDF 文件|任意应用窗口或整个桌面|
|画面清晰度|高，按文档内容传输|取决于窗口分辨率与网络|
|参会人浏览|支持跟随 / 自由浏览，可协同编辑|跟随共享画面，不能单独浏览文档|
|适用建议|课程讲授、材料讲解、协同讨论|演示本地软件、网页或需要操作演示的场景|

# 七、常见问题与注意事项

- **共享窗口最小化后画面暂停**：共享窗口时若将该窗口最小化，共享将自动暂停，演示前请保持窗口可见。

- **键盘翻页无效**：开始共享后，输入焦点在会议控制栏上，需手动点击幻灯片画面获得焦点后再用方向键翻页。

- **妙享权限**：主持人可在工具栏「安全」中设置共享权限（仅主持人可共享、仅主持人可抢占共享等）；妙享模式是否默认开启也受管理员后台设置影响。

- **会议中标注权限**：共享人可设置「仅共享人可标注和编辑白板」，控制参会人的标注权限。

- **远程控制**：参会人可通过飞书会议室触屏版远程控制共享人屏幕，但投文档（妙享）、共享白板或有线投屏时不支持远程控制。

# 八、演示结束

1. 点击共享画面中的 **停止共享** 按钮，结束演示。

2. 如需继续演示其他内容，可重新点击「共享」选择新的窗口或文档。

以上操作均可在飞书桌面端（Windows / macOS）完成，移动端入口略有差异：点击会议界面底部工具栏「··· 更多 \> 共享」发起共享。若遇到客户端版本差异，以实际界面为准。
