# 具身打磨项目调研报告

# PCL

PCL（Point Cloud Library，点云库）是面向二维、三维点云处理的开源 C\+\+ 库，常用于机器人感知、三维视觉、激光雷达、三维重建和工业检测。

它提供点云读写、滤波、特征提取、空间搜索、分割、配准、表面重建和可视化等模块，可支持从原始点云到目标识别、位姿估计的处理流程。PCL 采用 BSD 许可证，可用于科研和商业项目。[PCL 官方介绍](https://pointclouds.org/)

[PCL点云库文档](PCL点云库文档__wiki-LIHCwbuAXipsZYki7nOclnFYnGb.md)文档已整理学习资料、开发配置和实验素材，形成了从环境搭建到实践验证的入门资源：

前期工作已完成开发环境搭建与基础验证。 配置文档记录的环境为 Windows 11、Visual Studio 2022 和 PCL 1\.15\.0，涵盖 PCL、OpenNI2、调试符号、环境变量以及头文件、库文件和链接依赖的配置。同时整理了可复用的 Debug、Release 属性表。基础测试包含随机点云生成、八叉树半径近邻搜索和三维可视化，文档展示了红色立方体点云的运行结果。

# 视觉检测

### 论文一：Automated 3D Burr Detection in Cast Manufacturing using Sparse Convolutional Neural Networks

该论文面向铸件自动去毛刺场景，提出了一套 "深度学习 \+ 几何方法" 的混合毛刺检测方案：利用稀疏卷积神经网络（Sparse CNN）与 U\-Net 对 CAD 点云和真实扫描点云做深度特征提取与特征匹配，解决 CAD 模型与真实扫描点云之间的可靠配准问题；配准后再用几何方法定位毛刺区域、重建正常表面并量化毛刺高度。针对真实工业数据不足的问题，训练数据主要由 CAD 模型转换得到的高密度点云，经随机旋转、随机平移、尺度变化、点位置扰动等大量数据增强来模拟真实扫描获得。该方法解决了真实铸件存在铸造收缩、局部变形等制造误差，以及扫描点云存在点缺失、噪声、遮挡时，毛刺定位困难、毛刺高度难以量化的问题。

### 论文二：Towards Scalable 3D Anomaly Detection and Localization

该论文面向通用 3D 点云异常检测与异常定位，提出了两个核心工作：一是 Anomaly\-ShapeNet 异常数据合成方法，基于已有的正常三维模型人为添加局部异常（凸起、凹陷、裂纹等），程序主动添加异常使得每个点自动获得正常 / 异常标签，大幅降低三维点云的标注成本；二是 IMRNet 检测网络，采用 "训练时仅使用正常点云" 的掩码重建（Mask Reconstruction）策略，将点云划分为局部 Patch 随机遮挡后用 Transformer 恢复，让模型学习正常物体应有的几何结构而非学习各种异常形态，并配合几何感知采样（Geometry\-Aware Sampling）优先保留曲率、法向变化明显的区域，避免下采样丢失面积小但几何变化明显的异常。该方法解决了真实 3D 异常数据采集与标注成本高、单视角检测存在视野盲区、随机下采样容易删掉小异常区域、异常类型无法穷举导致监督学习扩展性差等问题。

### 论文三：Flash Extraction and Grinding Path Fitting Based on Point Cloud of Casting Parts

[ZHY Casting 文章方法操作说明](ZHY_Casting_文章方法操作说明__wiki-C0T5wJdJYiPjcVkbcJ2c241gnae.md)

该文章面向铸件分型面飞边的自动打磨场景，提出了一套"标准件配准 \+ 点云求差"的飞边提取与打磨路径拟合方案：先利用体素网格下采样压缩点云数据量，再以 RANSAC 粗配准与 ICP 精配准把待打磨铸件点云与标准无缺陷铸件（或其 CAD 派生点云）对齐到同一坐标系，解决了实物铸件与标准模型坐标系不一致、无法直接比对的问题；配准后利用 K\-D 树最近邻搜索，以点到标准模型表面的距离是否超出容差判定飞边点，并经统计滤波剔除离群点，解决了飞边区域定位的问题；进而采用点到面的距离估计（在标准模型表面取最近点与其邻域拟合局部平面后计算有符号距离）量化飞边的高度分布，为打磨深度的设定提供依据；最后将铸件本体点云沿主导轴投影为二维图像、用 Canny 边缘检测提取外轮廓，经下采样拆分为拟合点集与验证点集，并以三次 NURBS 曲线插值生成连续光滑的打磨路径。该方法解决了铸件存在个体差异与形变、标准模型与实物不符，以及飞边高度难以量化、打磨路径难以针对单件自适应生成的问题。

### 论文四：基于铸件飞边点云信息的机器人打磨规划方法研究

[周海陶论文方法操作说明](周海陶论文方法操作说明__wiki-JuGow4ocxi79VWklHKYcaUqYnYh.md)

该论文面向水平分型面铸件的飞边自动打磨场景，提出了一套"点云模型构建 \+ 几何特征提取"的飞边打磨点提取方案：利用双目相机采集铸件多视角点云，经设备标定、统计滤波去噪与 ICP 配准拼接构建完整的铸件点云模型，并采用 DGCNN 语义分割网络将其粗分为铸件本体、铸件飞边与环境背景三部分，解决了原始点云混有噪声与背景、无法直接定位飞边区域的问题；随后利用基于法线估计的边缘检测提取飞边边缘点，结合 K\-D 树半径搜索，依据"内边缘紧邻铸件本体、其邻域内本体点数更多"的特征区分飞边的内外边缘，保留内边缘并以其高度均值确定机器人打磨的位置高度，解决了飞边在铸造与搬运过程中发生翘曲、导致打磨高度难以确定的问题；最后将本体点云投影至内边缘所在平面实现扁平化处理，经边缘检测与 DBSCAN 聚类剔除内腔轮廓、保留水平分型面外边缘，并用改进的体素下采样算法生成打磨路径拟合点集与评价点集，解决了内腔边缘干扰打磨路径、边缘点过密影响拟合效率的问题。该方法解决了水平分型面铸件在飞边位置随机、表面存在翘曲与粗糙等情况下，打磨高度难以确定、打磨点提取不完整的问题。

### 论文五：基于点云语义分割的铸件飞边识别算法研究

该论文面向铸件飞边自动打磨场景，提出了一套"点云语义分割 \+ 数据生成"的飞边识别方案：利用自研的点云语义分割网络 MSF\-Net 对铸件扫描点云做逐点语义分类，解决人工定义特征难以有效定位飞边的问题；通过引入融合全局与局部特征的上采样算法 UFLG，解决上采样视野窄、难以结合飞边在铸件上的整体位置综合判断的问题；网络除输出飞边与铸件本体外，另单独标注"铸件侧面"一类，为后续打磨提供刀具姿态引导。针对飞边样本采集与标注成本高的问题，训练数据主要由三维建模生成的多型号铸件仿真点云经随机拉伸、随机采样、点位置扰动等数据增强模拟真实扫描获得，并利用基于生成对抗网络的 FPG\-Net 与飞边漂移算法 k\-shift 自动生成新的飞边样本以扩充数据集，同时借助大规模公开数据集预训练后迁移来提升特征提取能力。该方法解决了真实铸件扫描点云存在环境噪声干扰、局部视野受限，以及飞边位置、形状与厚度随机时，飞边识别精度不足、训练样本稀缺且换型后泛化困难的问题。

# 轨迹规划

### 论文一：Development and Experimental Evaluation of a 3D Vision System for Grinding Robot

该论文面向工件装夹位置变化后固定示教轨迹无法准确对应实际加工目标的问题，提出了一套机器人 3D 视觉加工点生成方法：先用 VoxelGrid 对扫描点云降采样，再通过 FPFH/SAC\-IA 完成粗配准、ICP 完成精配准，并以 FLANN 最近邻搜索提取实测点云与基准点云之间的几何差异；随后根据差异区域和表面法向生成加工点，并通过球靶标定、MDH 误差模型和 SVD 补偿将加工信息转换到机器人坐标系。该方法解决了目标位置变化时加工点提取和坐标转换的问题。论文未明确报告完整作者代码，但相关点云流程可用 PCL/Open3D、Eigen 和机器人 SDK 实现。

### 论文二：A Robotic Deburring Methodology for Tool Path Planning and Process Parameter Control

该论文面向复杂铸件边缘去毛刺时刀具姿态难调整、加工余量不均且加工状态易波动的问题，提出了一种结合刀具路径规划和工艺参数控制的方法：根据工件边界点的切向和法向建立刀具姿态，按加工余量和切深沿法向生成分层路径，并通过相邻轨迹重叠的往复覆盖减少漏磨；加工过程中再用模糊控制，根据主轴转速和负载误差调整主轴电压及机器人进给速度。该方法将边缘几何、分层去除和加工状态反馈结合起来。论文未明确提供通用规划代码，路径几何可基于 PCL/Open3D、Eigen 和机器人 SDK 实现；具体工艺参数需结合实际磨头和材料重新确定。

### 论文三：Automatic Aluminum Alloy Surface Grinding Trajectory Planning

该论文面向大型铝合金曲面焊缝和缺陷定位困难、平面路径投影到曲面后轨迹间距失真以及焊缝余高未知的问题，提出了一套融合二维图像和三维点云的轨迹规划方法：先从二维图像中识别焊缝并映射到三维点云，再通过点到曲面的正交投影估算焊缝余高；对长条焊缝沿中心线规划轨迹，对面状缺陷则依据曲面切片和弧长等距采样生成空间螺旋路径，并利用曲面法向确定工具姿态。该方法提高了曲面上的路径覆盖连续性，并将焊缝几何信息纳入规划。论文使用 RoboDK 仿真和开源 ARIS 控制库，但未形成通用路径规划开源包；曲面切片、采样和螺旋生成可基于 PCL/Open3D、Eigen 及机器人接口重建。

### 论文四：Adaptive Robotic Deburring via 3D Vision and Tolerance\-Constrained Non\-Rigid Registration

该论文面向成型件存在翘曲和制造公差、刚性配准可能将形变误认为毛刺，以及固定进给速度容易导致过磨或效率不足的问题，提出了一套基于 3D 视觉的自适应去毛刺路径方法：通过多视角扫描和公差约束非刚性 ICP 对齐实物与参考几何，再分割毛刺点云、统计毛刺高度，并用样条曲线平滑加工轨迹；最后根据毛刺高度与预实验得到的工艺关系调整进给速度。该方法将制造公差、缺陷几何和加工速度联系起来。论文使用 Python、Open3D 和 CloudCompare，但未见完整通用作者代码包；点云处理和轨迹平滑可由 Open3D/PCL、SciPy/Eigen 等组件重建，软材料验证结果向金属工件迁移时需谨慎评估。

### 论文五：Point Cloud Based Model\-Free Path Planning for Large Complex Forgings

该论文面向大型锻件热变形和随机飞边、氧化皮等缺陷使固定 CAD 或示教轨迹难以匹配实际工件的问题，提出了一种基于点云差异的路径规划方法：将实测锻件点云与标准件参考点云通过 RANSAC 和改进 ICP 配准，提取待加工差异区域后按面积分类；小区域生成中心或局部加工路径，大区域则根据 AABB 包围盒和切片生成往复覆盖路径。该方法根据缺陷尺度选择不同的路径形式。论文使用 Qt 自研软件并生成机器人 RAPID 程序，但未明确提供完整作者代码；主要点云和路径模块可用 PCL/Open3D、Eigen、Qt 及机器人仿真接口重建。需要注意，该方法仍依赖标准件点云作为参考。

### 论文六：视觉引导的打磨机器人轨迹规划及运动控制研究

该论文面向铸锻件毛刺、飞边与浇冒口残余长期依赖人工打磨、自动化普及率低的问题，提出了一套融合三维视觉感知与智能轨迹规划的加工方法：先用面结构光扫描获取工件稠密点云，完成相机内外参、工具坐标与铸件场景手眼标定后，对点云做有效区域提取、多级降采样、统计滤波与曲面拟合平滑，并在此基础上提取点云边缘特征点；再用改进的区域生长算法把曲面与平面特征分割开，按两类特征面各自的打磨要求规划打磨间距，得到对应的打磨轨迹曲线；最后按打磨压力与效果要求提取各点法向量，生成带姿态的机器人路径，并在运动学建模基础上设计双层结构预测控制的动态轨迹规划，同时考虑关节运动约束与末端接触力波动。该方法把点云质量、边缘特征、间距规划与姿态生成串成一条完整链，并通过实验验证了视觉引导轨迹规划的可行性。论文未提供开源代码，其中点云预处理与法向估计可用 PCL/Open3D 实现，间距与姿态生成需自行实现，动态轨迹部分依赖模型预测控制与机器人控制接口。

### 论文七：Application Research of Vision\-Guided Grinding Robot for Wheel Hub Castings

该论文面向轮毂铸件毛刺粗磨仍以人工为主、毛刺位置与高度存在随机性的问题，提出了一套视觉引导的打磨机器人方法：先通过视觉系统标定建立像素坐标系到机器人基坐标系的转换关系，保证后续提取的毛刺点坐标能够正确映射到机器人作业坐标系；再采集轮毂铸件毛刺图像并用图像算法提取全部毛刺点，形成待打磨点集；为弥补定位与高度上的偏差，进一步引入高度误差补偿模型以提升打磨精度，并完成实验验证。该方法把标定、缺陷提取与高度补偿连成一条可直接落地的加工链，与本项目轮毂类零件的切入场景高度一致。论文未公开通用代码，标定与图像处理可用 OpenCV/Halcon 与机器人 SDK 实现，高度补偿模型需按现场工件与磨头重新标定。

### 论文八：面向焊缝稳定加工的机器人打磨路径规划

该论文面向大型铝合金焊缝打磨中机器人刚度随位姿变化导致颤振、且易产生过切的问题，提出了一种兼顾本体性能的路径规划方法：先建立机器人的奇异性指标与刚度性能模型，求解既不产生奇异又能保持良好刚度的关节角范围；再将工件与打磨系统按尺寸等效建模，分析无碰撞条件；最后在该可行角域内用内接三角形法规划焊缝打磨轨迹。方法以高铁车体侧墙长焊缝为对象，焊缝余高 2 至 5 毫米、宽度约 10 毫米，求解得到关节 2 与关节 3 的安全角域分别为 20\.63° 至 123\.82° 与 \-0\.57° 至 62\.48°，并给出一条可稳定打磨的弧线轨迹。该方法的价值在于把机器人本体约束前置到路径生成阶段，而非事后做碰撞检测。论文未提供代码，刚度与奇异性建模可基于 D\-H 运动学与雅可比矩阵实现。

### 论文九：复杂曲面机器人磨抛位姿优化与刀具路径规划

该论文面向复杂曲面磨抛中刀位点按曲率与法线方向划分、未考虑机器人姿态变化对路径光滑性的影响且可能存在工具干涉的问题，提出了一种以姿态变化为约束并光顺干涉处姿态的规划方法：先以机器人末端磨抛姿态的变化量作为刀位点划分阈值，并综合考虑非法线方向的位姿变换，减缓相邻刀位点之间的姿态突变；再在干涉位置改变刀具姿态，并以等参数圆做范围性光顺；最终规划出一条光滑且无碰撞的机器人磨抛路径。方法在机器人砂带磨抛系统上对航空发动机叶片验证，关节角速度变化平缓，磨后叶片轮廓度满足 \-0\.03 至 \+0\.05 毫米公差带，表面粗糙度由 Ra 大于 3\.2 微米提升至 0\.2472 微米。论文未提供开源代码，位姿约束划分与干涉光顺可基于 Open3D/PCL 与机器人运动学库重建。
