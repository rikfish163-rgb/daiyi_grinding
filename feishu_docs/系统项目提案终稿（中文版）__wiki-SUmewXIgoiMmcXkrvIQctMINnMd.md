# 项目背景与引言

MATHCOUNTS是一项面向热爱数学和问题解决的中学生的全国性竞赛系列。在倒数回合（Countdown Round）中，2至6名参赛选手会面对一道题目，并有20至60秒的时间作答。每位选手都有一个按钮单元，通过线路连接到位于比赛操作员面前的中央控制台。第一个抢答的选手回答问题，根据规则，要么允许第二个抢答的学生回答，要么让其余学生获得再次抢答的机会。只有第一个被按下的抢答器才会触发灯光和声音。比赛操作员可以切换到下一个抢答的选手、重置按钮单元、切换操作模式以及管理计时器。中央控制台上会放置一个小计时器，供操作员查看，另有一个较大的计时器面向参赛选手。两个计时器显示相同的时间，并由比赛操作员控制。操作员通过启动、重置或更改显示时长来管理计时器（只要计时器当前不在倒计时中）。几十年来，Rose\-Hulman本校一直使用同一套抢答系统，而该系统目前依赖一台极其过时的计算机。加之系统多年运行已严重磨损，人们担心它可能很快失效。因此，我们的目标是在保留现有系统基本功能的同时，对其进行现代化改造，使其更耐用、更易用。

重新设计的系统预期至少可使用10年，将使用Arduino微控制器，连接6个按钮单元、2个计时器显示屏以及中央控制台上的一组按钮输入。将采用I2C通信以减少引脚占用，以太网线缆则提供组件之间的耐用连接。该设备工作电压为5V，通过标准120VAC墙壁插座供电；定制PCB将确保设计稳健，并提供易于插拔设备的端口。系统将通过控制器上的一个开关设置两种模式：类型1模式（重置抢答盒）和类型2模式（下一位作答）。在类型1模式下，当某位选手第一个按下按钮时，操作员将重置所有抢答器；如果回答错误，任何选手都可以再次抢答并给出不同答案。在类型2模式下，系统会记住所有按钮被按下的顺序，因此当某位选手回答错误时，操作员可以按下"下一答案"（Next Answer）按钮，切换到下一位抢答的选手。这两个功能由同一个物理按钮操作，但通过拨动"切换模式"（Change Mode）开关来改变其效果。在两种模式下，计时器都不会因选手抢答而停止。此外，通过使用"计时增加"（Timer Up）和"计时减少"（Timer Down）按钮，可以以5秒为增量改变计时器的时间长度，范围为20秒至60秒。

# 项目交付物

提供一套满足客户提供的《MATHCOUNTS抢答系统——类型1与类型2组合设备规格书》修订版1\.0（日期2024年10月19日）要求的系统，并包含：

- 一个使用墙壁插座为控制器供电的功能正常的电源

- 六个使用以太网连接到控制器的按键盒

- 每个按键盒上有一个LED/灯，当选手按下按钮时亮起

- 一个向参赛选手显示剩余时间的七段数码管显示屏

- 一个在按键与操作员之间起交互作用的主控制器，包含：

- "计时增加"和"计时减少"按钮，用于将计时器开始时间设置为20至60秒之间的任意值，以5秒为增量

- 一个"重置计时器\+抢答盒"按钮，用于重置计时器和六个按键盒

- 一个"开始计时"按钮，用于开始计时

- 一个"重置抢答盒/下一答案"按钮，用于重置按键盒，并根据模式决定是否切换到下一位作答者

- 一个"切换模式"开关，用于在系统的两种模式之间切换

- 一个蜂鸣器，在时间耗尽或选手按下按钮时发声（共三种声音——一种用于超时，两种用于抢答）

- 操作员控制器上的一个七段数码管显示屏，用于显示剩余时间

# 交互模型

表5：交互及描述

|交互|描述|
|---|---|
|模式选择开关被拨动|系统将根据该开关的位置，以类型1或类型2操作模式运行。|
|"计时增加"或"计时减少"按钮被按下|允许作答的最大时间分别增加或减少5秒。这将反映在计时器显示上。这些值不会超过60秒或低于20秒，并从60秒开始。在计时器运行期间（学生正在作答时）按下这些按钮不会影响计时器——它们只会在"重置计时器"被按下之后、"开始计时"被按下之前生效（或仅在系统刚上电、首次按下"开始计时"之前生效）。|

|参赛选手按钮被按下|如果这是第一个被按下的按钮，相应的灯亮起并响起蜂鸣声。<br>在类型1模式下，所有其他选手的按钮均被停用。<br>在类型2模式下，所有其他选手按下的按钮将按接收顺序被记录。|
|"蜂鸣器重置/下一答案"按钮被按下|类型1模式：作答选手的灯将在20ms内熄灭，所有选手按钮被重新激活。<br>类型2模式：作答选手的灯将在20ms内熄灭，下一位按下按钮的选手的灯将亮起。之前作答选手的按钮将被停用。|
|"计时器重置"按钮被按下|在两种模式下，所有灯熄灭、所有按钮重新激活、计时器重置为选定的起始值。所有这些均在20ms内完成。|

# 预算与采购计划

采购计划：

项目的零件订单将通过两种途径之一进行。大多数零件将通过Rose\-Hulman ECE系订购，余额将累计至项目结束时支付；Rose\-Hulman可能会补贴部分余额，具体由ECE系最终决定。部分零件将由开发团队直接订购。在这些情况下，收据将被累积，余额和收据清单将在每个季度末发送给客户。发送余额时将提供账单信息。
