# 基于公共数据集的PointNet\+\+和相关点云视觉检测网络训练（2）

# **实验内容与目的**

基于论文[Point Cloud Segmentation of Integrated Circuits Package Substrates Surface Defects Using Causal Inference: Dataset Construction and Methodology](Point_Cloud_Segmentation_of_Integrated_Circuits_Package_Substrates_Surface_Defec__wiki-Ks5BwGjb8iyvCKkSRI2cN8G4ned.md)中介绍的陶瓷封装基板表面缺陷分割任务和数据集，和论文[3D\-ADAM论文阅读](3D-ADAM论文阅读__wiki-BkZgwoJX6iBeFCkmOqDccw3bnvb.md)3D\-ADAM: A Dataset for 3D Anomaly Detection in Additive Manufacturing中的3D\-ADAM数据集，在工作站中进行 PointNet\+\+和相关网络中训练工件异常检测网络，探索合适的数据处理方式，网络结构和训练配置，为使用真实点云和自建数据集训练做准备。

**本周阶段性结果**：基于CPS3D\-Seg数据集，针对pointnet\+\+网络，探索出加入局部表面特征描述、更改分块点填充方式和扩大分块大小对训练是有较小收益的；PTv2网络且使用4096点分块的效果明显优于前面的方法。基于3D\-ADAM数据集的pointnet\+\+的训练目前几乎无效，还需进一步诊断修改。

# **实验配置**

工作站：显卡 RTX A5000 24G 内存 32G（原128G） Windows 11 python 3\.12\.16  pytorch 2\.14\.1\+cu130 CUDA 13\.0

# 实验步骤与结果

## 基于CPS3D\-Seg数据集的陶瓷封装基板表面缺陷分割任务

上次的结果

|阶段|训练配置或变化|缺陷平均准确率AP|召回率Recall|
|---|---|---|---|
|Pointnet\+\+修正评估点序|**沿用上一行权重，不增加训练**|30\.96%|30\.54%|
|上一步低学习率微调|增加 1,600 步；无增强、学习率 0\.0001，选中第 480 步|31\.72%|31\.32%|
|PTv3|随机初始化训练 3,200 步；有效 batch 128，BF16，选中第 1,600 步|**35\.28%**|**32\.48%**|

1. 改变随机中心点取邻域点的算子，原算子在半径内按输入索引截取，试验组改为按距离取最近邻，二者都使用原有的重复补点。从同一旧权重各微调 640 步，采用相同的块2048点、FP32、批量 128 和学习率。

|方案|入选步|缺陷 AP|召回|
|---|---|---|---|
|原算子|0|35\.48%|37\.48%|
|半径内最近邻|640|8\.87%|9\.99%|

结果不如更改算子前。

2. 从完整工件为每点计算 12、32、64 近邻的局部表面描述，共 27 维。在 112 个训练工件上拟合几何分类器，将其对数几率加到原 PointNet\+\+ 的对数几率上。

|方案|AP|召回|
|---|---|---|
|原 PointNet\+\+|35\.48%|37\.48%|
|PointNet\+\+ 与几何分数融合|**37\.62%**|**39\.27%**|

几何分数融合比原模型多检出 5,195 个缺陷点，AP 提高 2\.14 个百分点。

3. 原2048点块的循环重复补点占训练输入的40\.8%、验证输入的23\.4%。抽查64个验证工件，在6765个缺陷查询点里约23%至少有一个整件近邻落在别的块。改为用同一工件中最靠近块内任一点的块外真实点补足输入。

|方案|AP|召回|
|---|---|---|
|原最佳权重，重复补点|35\.48%|37\.48%|
|块外补点训练及推理|**36\.92%**|**38\.14%**|

训练和推理统一采用块外近邻后，同为640 步，新方案 AP \+1\.82 个百分点、固定误报率召回 \+0\.96 个百分点，多检出 2766 个缺陷点。

4. 探索点云分块大小对训练效果的影响，同用块外补点、随机初始化、1600 步，保持每步 262,144 个输入位置分块大小为1024、2048、4096三组。

|块上限 × 批量|AP / 召回|
|---|---|
|1024 × 256|26\.82% / 29\.25%|
|2048 × 128|34\.68% / 36\.93%|
|4096 × 64|**36\.31% / 37\.35%**|

4096 点的从头训练结果最好，且速度最快。但是效果和步骤3没明显区别。

5. PTv2网络试跑和分块大小实验，两版沿用同一批工件、同一随机初始参数以及块外补点，均从头训练 1600 步。BF16 训练、FP32 验证和模型结构一致。批量 128 与 64 对应相同的 262,144 个输入位置。

|PTv2 方案|最优检查点（步）|AP / 召回|
|---|---|---|
|2048 × 128|640|38\.34% / 39\.63%|
|4096 × 64|960|**46\.04% / 47\.75%**|

4096分块版本的PTv2比明显优于前面所有结果。

## 基于3D\-ADAM数据集的pointnet\+\+缺陷检测网络训练

使用MechMind\-Nano子集中200 次扫描、25个编号组的监督开发子集制作数据集，训练/验证/测试为 136/32/32 次扫描。进行了多组不同配置的PointNet\+\+网络训练。包括原配置基线，训练集BN校准，最近邻、真实点掩膜，专门选用毛刺缺陷重新制作数据集以避免特征种类过多无法区分。但是所有实验的ap均未超过3%，暂不清楚训练几乎无效的原因。
