# 上海戴屹科技有限公司简介

上海戴屹科技有限公司（简称“戴屹科技”）是一家专注于铸造后清理自动化集成领域的高新技术企业，成立于2015年6月4日。公司由留学德国的邓念皓先生携德国KUKA机器人原班核心团队创立，致力于改善铸造行业（Dirty, Difficult, Dangerous）的工作环境，提升制造效率与产品质量。

### ⚙️ 主营业务

戴屹科技集自动化生产线、机器人后清理生产线、机器人去毛刺系统的研发、设计、制造、安装、调试于一体，具备国内一流的综合开发能力。其核心业务包括：

- **机器人打磨单元**：涵盖抓工件打磨单元和抓工具打磨单元

- **铸件后处理整线**：提供铸件后处理自动化整线解决方案

- **非标定制专业自动化打磨设备集成**

- **应用领域**：黑色金属打磨、有色金属打磨、铸造工业4\.0自动化车间等

    

公司经营范围广泛，涵盖智能机器人研发、人工智能硬件销售、人工智能应用软件开发、工业机器人制造与销售、工业机器人安装维修、机械设备研发销售租赁、信息系统集成服务、货物及技术进出口等。



### 🔬 技术实力与资质荣誉

- **知识产权**：持有34项专利、19项软件著作权及3项商标

    - 2025年1月取得“一种安装拆卸方便的机器人力矩测量装置”专利

    - 2025年8月取得“一种减震塔去毛刺成套设备打磨抓手”专利

        

### 📈 发展历程

- **2015年**：公司完成工商注册，由邓念皓等人正式创立，专注于打磨机器人领域。

- **2018年**：签约泰州医药高新区5亿元智能制造项目。

- **2019年**：将总部迁至江都，成立德屹智能科技（扬州）有限公司；同年，在西安设立技术研发中心。

- **2020年**：获得中国建设银行贷款300万元。

- **2022年**：获评高新技术企业。

- **2023年**：入选省级专精特新中小企业。

- **2025年**：公司经营范围发生变更，高新技术企业认证年份为2025年。

    

### 👤 创始人

邓念皓先生，2004年毕业于德国慕尼黑工业大学，曾任职于德国KUKA机器人公司。2009年，他将“机器人\+打磨”作为研发方向进入该领域，2015年正式创立上海戴屹科技有限公司。
