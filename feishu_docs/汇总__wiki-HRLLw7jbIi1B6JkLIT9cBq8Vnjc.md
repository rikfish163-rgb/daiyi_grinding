# 汇总

# 一、汇报结论

这 12 篇论文覆盖了机器人打磨系统的主要技术方向：

视觉定位与点云配准、毛刺/焊缝识别、曲面轨迹规划、力控执行、过程监测、无序抓取和 AI 辅助编程。

总体来看，当前研究重点已从固定示教轨迹，发展到基于 3D 视觉的自适应路径规划，并进一步结合力控和加工状态监测。但各模块仍较分散，复杂工件的统一闭环方案尚未成熟。

对 VGS 而言，技术调研应重点关注：

• 3D 点云如何转换为可靠的缺陷区域和轨迹；

• 不同缺陷类型对应的路径规划方法；

• 机器人运动学、碰撞检测与工艺参数的协同；；

• AI 在缺陷识别、参数决策和减少人工编程中的作用。

总体技术趋势是：

3D视觉感知 \+ 几何/优化轨迹规划 \+ 运动与碰撞约束 \+ 力控加工 \+ 在线质量监测 \+ AI辅助决策。

目前 AI 更适合辅助感知、分类和参数决策，完整的打磨轨迹仍需要几何、机器人和工艺约束共同保证。

## 面向 VGS 的推荐技术链



```Plain Text
3D扫描
→ 标定/滤波/配准
→ AI与几何方法联合识别缺陷
→ 按缺陷类型选择中心线、分层边缘、栅格或螺旋路径
→ 法向姿态、刀具半径补偿、速度/转速/压力规划
→ 逆运动学、关节限位、奇异位形和碰撞检查
→ 力控执行与过程信号采集
→ 加工后扫描复检
→ 漏磨/过磨/节拍/粗糙度评价
```



**工程原则：** AI 负责缺陷检测、分型、候选路径排序和参数建议；几何、运动学、碰撞和工艺模块负责约束与执行。暂不建议让端到端网络直接输出未经校验的机械臂轨迹。
