# 基于公共数据集的PointNet\+\+和相关点云视觉检测网络训练（1）

# **实验内容与目的**

基于论文[Point Cloud Segmentation of Integrated Circuits Package Substrates Surface Defects Using Causal Inference: Dataset Construction and Methodology](Point_Cloud_Segmentation_of_Integrated_Circuits_Package_Substrates_Surface_Defec__wiki-Ks5BwGjb8iyvCKkSRI2cN8G4ned.md)中介绍的陶瓷封装基板表面缺陷分割任务和数据集，在戴屹提供的工作站中进行 PointNet\+\+ 与 PTv3 网络的试训练，进一步评估训练开销，探索未来使用真正的工件点云数据进行训练时可能需要的调整。

# **实验配置**

本机：显卡 RTX 5060Ti 8G 内存 24G Windows 11

工作站：显卡 RTX A5000 24G 内存 128G Windows 11

两边均使用 CPS3D\-Seg、XYZ 输入、最多 2,048 点/块及 o1/o2/o3 分组。本机和工作站的实验的实现细节、点序设置、batch和预算有一些差异。

# **实验结果分析**

1. 最开始在本机上的640步的训练不足以充分学习，预算和batch较小导致样本曝光量不足。

2. 修正点序能够有效提升评估效果。

3. 6400步训练已经出现过拟合的迹象；PTv3 效果略强于 PointNet\+\+; 低学习率的微调可以小幅度提升准确率

4. 目前所有实验结果的准确率均偏低，点云处理方式，网络结构和训练配置仍须大量优化。

# **下一步**

1. 我们的部分工件点云可能达到百万量级，远大于此论文提供的数据集中单个点云的大小。CPS3D\-Seg全数据集约1\.08亿，进行实际实验时需要结合我们工件点云数据集的规模，调整分块尺寸和训练覆盖方式，保证正确保留飞边毛刺信息，同时不超出实际显存资源。一个块需要同时包含飞边、根部和附近正常本体，才能帮助模型判断哪些结构应当去除。

2. 使用3D相机扫描真实工件并检查实际数据，统计点数、局部点间距、缺点和重复点，人工确认最小飞边及根部是否实际被扫描到。

3. 建立工件整件检测基线，补充工件级评价：针对我们的工件缺陷检测场景，跑通“分块—预测—还原”检测流程，检查全部有效点是否被覆盖，并记录每件耗时，并加入飞边区域召回率、整段漏检、误报区域数，以及根部定位误差等工件级评价指标。
