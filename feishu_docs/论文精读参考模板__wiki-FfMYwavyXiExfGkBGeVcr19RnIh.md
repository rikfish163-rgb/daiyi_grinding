# 问题1: 作者研究什么问题？作者为什么想研究这个问题？

> （研究动机）
> 
> 提示：请使用1句话提炼本文研究的问题，作者使用了什么方法（文献、数据、案例？）来说明该问题，建议首先进行宏观性的问题描述，而不要直接在绪论部分开始直接讨论具体的方法。建议提供一张示意图，表述问题场景，例如介绍MAC 层在网络中的重要性？行文的基本原则是通俗易懂，自己的爷爷奶奶听得懂自己在做什么研发工作？
> 
> 问题，按其性质至少包含三种类别层次：（1）Issue，是讨论涉及的议题、话题，一般在宏观层面（后简称I问题）；（2）Problem，是疑难、未知、有争议、有矛盾的问题（后简称P问题）；（3）Question，针对有待分析和解决的探究性问题（后简称Q问题）。经过这样的分析转化，不仅让问题更聚焦，也因批判性思维的认知机制而提出更值得研究的好问题。
> 
>
