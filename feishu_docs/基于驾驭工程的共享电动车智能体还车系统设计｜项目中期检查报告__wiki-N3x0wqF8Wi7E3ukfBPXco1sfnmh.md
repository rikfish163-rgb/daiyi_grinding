# 总体技术路线

项目解决的是共享电动车归还环节的停放合规判定问题：用户归还车辆时拍摄车辆及周围环境，系统依据图片判断停放是否合规。系统采用端云协同方式，前端负责拍照引导和部分实时检测，云端使用 Flask 部署服务，结合 YOLOv8\-Seg 与 Qwen\-VL 分析车辆及周围环境。

由于系统最终依据图片作出判断，照片的视角、位置和光照会直接影响判定结果。因此项目并未只优化云端算法，同时改进了前端采集环节，引导用户把车拍正、拍全、拍清楚，使进入云端处理的图片更接近算法可用的理想输入。

# 研究进展情况

## 停车角度计算：从三维流程转向二维掩膜 PCA

原方案先对车辆做实例分割和深度估计，再把图像转成点云，经滤波、平滑和三维 PCA 后投影到地平面，最后计算车辆与停车线之间的夹角。这条链路步骤多、耗时长，对算力要求也高；部分样本缺少相机内参，重建出的点云存在畸变，前面步骤产生的误差还会向后续计算传递。

地平面的确定是原方案的另一个难点。图片本身没有直接提供地平面参考，需要利用车轮底部点云和停车标线拟合；车轮位置提取不准，或者标线在图片中不够清晰，拟合出的平面就会偏差，车辆角度也随之失真。针对这两个问题，项目减少对深度估计和三维重建的依赖，寻找计算过程更短的做法。

当拍照视角正对车辆时，可以直接用车辆在二维图像中的形状估计方向：先通过实例分割得到车辆掩膜，再对掩膜做 PCA 提取车辆主轴，最后计算主轴方向与停车线或路缘方向之间的夹角。与三维流程相比，该方法不需要还原点云，也省去了地平面拟合。答辩材料显示，在相应的测试条件下，角度误差小于 5°。

## 前端拍摄引导设计

二维方法对拍摄视角有要求：用户从侧面或较偏的位置拍摄时，车辆在图像中的形状发生变化，直接算出的角度会受影响。为了让用户尽量正对车辆拍照，项目在客户端设计了 AR 引导界面，把算法对输入的要求翻译成用户看得懂的画面提示。

拍摄界面用双椭圆引导框标示车辆应该在画面中的位置，并结合 YOLO 的实时检测结果，通过方向箭头提示用户调整手机或拍摄位置。车辆的居中程度由端侧根据检测结果计算并做归一化处理，用户据此判断是否需要继续调整；这样可以在提交图片之前就发现车辆偏离画面中心、拍摄角度过偏等问题，减少后端收到不可用样本的情况。

客户端还处理了车牌与光照两个影响识别效果的因素：车牌部分使用 ML Kit OCR 进行识别，并结合检测与追踪，使拍摄过程中始终关注目标车辆；光照不足时做亮度检测，提示用户开启闪光灯。对于角度过偏、运动模糊或光线不足这几类常见问题，前端引导能在一定程度上改善输入质量，同时也要控制提示的密度，避免增加用户操作负担。

## 数据集整理与检测优化

前期测试使用的图片包含多种拍摄角度和复杂场景，与加入前端约束后云端实际接收到的图片存在差异；部分样本此前没有完整的四维标注，难以按不同判断依据拆开分析预测结果。为此，项目对 3256 张真实场景图片进行筛分，并补充四维判断依据标注，为后续比较不同场景、不同判断维度的效果提供数据基础。

针对检测能力不足的问题，项目补充了 YOLO 的训练数据，训练集由 733 张增加到 911 张。答辩材料显示，调整后电动车检出率达到 99\.5%，路缘检出率达到 44\.7%。车辆目标的检测效果较好，路缘等环境目标仍有较大提升空间；这些数据对应具体测试条件，实际应用效果还需结合不同场景继续观察。

## 检测结果与视觉语言模型的协同判断

还车合规判断中，车辆本身只是需要识别的一部分，车道线、盲道和路缘等环境信息同样重要。此前测试中，约 40% 的图片能够检测出相关环境目标，部分情况下检测结果不足以支撑完整判断，还需要视觉语言模型结合画面内容综合分析。项目围绕这一流程开展推理优化，并对典型合规与违规图片进行测试，检查检测结果与大模型判断在实际场景中的配合情况。

目前，项目已完成车辆角度计算、前端拍摄引导、数据集整理和检测优化等工作，并对云端服务进行了部署和测试。后续仍需补充复杂光照、遮挡和非标准拍摄视角下的样本，进一步提高路缘等环境目标的检出能力，同时继续核查系统运行速度和实际使用效果。

# 目前存在的问题

1. **拍摄视角对角度估计影响较大。**二维方法在正对视角下较稳定，侧面或较偏位置拍摄时车辆形状变化，加上遮挡、检测框不稳定，都会影响掩膜主轴提取的准确性。

2. **环境目标检测仍有不足。**路缘、车道线、盲道等目标受光照、遮挡和背景变化影响，检出率明显低于电动车；此前测试中能检出相关环境目标的图片约占 40%，判断仍需视觉语言模型补充。

3. **样本分布与实际业务存在差异。**现有样本以常见拍摄条件为主，复杂角度、画面残缺、运动模糊和弱光场景的覆盖不足，模型在这些条件下的表现缺少充分验证。

4. **推理速度与用户体验需要平衡。**检测、分割、角度计算与视觉语言模型判断串行执行，环节越多响应越慢；提升准确率与保持可接受的等待时间之间仍需权衡。

# 下阶段研究计划及主要措施

1. **补充复杂场景样本。**针对复杂光照、遮挡、画面残缺和非标准拍摄视角补充采集与标注，扩展测试集，逐类统计判定准确率，找出失效集中的场景。

4. **优化推理速度与部署方式。**精简云端处理流程，评估模型轻量化与端云任务划分的可行方案，在保证判定准确率的前提下缩短响应时间。

5. **扩大测试与成果整理。**在典型还车场景开展批量测试，形成速度、准确率与稳定性的指标记录，同步整理论文与项目材料。
