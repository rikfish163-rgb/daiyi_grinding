# 论文泛读参考模板

> 修订历史\(Revision History\)
> 
> 

1. 阅读动机（本文发表在哪里？作者是谁？我为什么阅读这篇论文？）

2. 研究问题Problem（本文拟解决什么问题，图文结合清楚表述，以问号结尾；鼓励将核心问题再进一步拆解为系列子问题，对应于方法和实验评估部分）；

3. 研究动机Motivation（本文聚焦的问题如何没有解决或者其他人解决得怎样不好；如果不是公认的重要问题，作者是如何说明本文的研究动机）；

4. 研究方法Solution（本文提出了什么解决方法，叙述解决该方案的思路，说明新的方法和手段）；

5. 性能评估Evaluation（本文提出的方法如何与已有的方法进行对比实验，说明性能改善程度）；

6. 论文讨论Discussion（讨论自己对论文的疑问，可能对自己或者项目组的研发工作有什么参考价值）。
