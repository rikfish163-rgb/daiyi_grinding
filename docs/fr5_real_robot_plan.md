# FR5 铸件批缝与局部毛刺初步真机计划

先用真实工件完成测量和坐标验证，再做主轴关闭的空跑，最后在可报废小样上开展受限接触。目标是建立从自动视觉选区到真实加工的证据链。当前 MuJoCo 演示验证观测、规划与运动，不证明材料去除、表面质量或 FR5 控制器行为。本计划的阈值和人天为研发建议，须结合工件与现场设备确认，不属于合同承诺。

## 工艺范围与开始条件

首版采用 FR5 持小型磨削工具、夹具固定工件，处理相机可见上表面的批缝和局部毛刺；保留人工 ROI。开始前确认工件材质、外形和重量，缺陷位置与最小宽高，必须保留的正常结构，允许残余、过切与粗糙度，既有工具、主轴及生产节拍。大型冒口、深腔和侧面倒扣需另行设计。

戴屹提供合格与不合格样本、夹持约束、既有工艺参数及质量人员；团队提供视觉、标定、规划、记录及接口适配；FAIRINO 或现场集成人员确认控制器和力控兼容性。接口、工具和工件未确定时，不能给出可靠的整线节拍或固定接触力。

## 最小硬件与接口清单

| 项目 | 最小试验配置 | 到场后核验 |
| --- | --- | --- |
| 机器人 | FR5、匹配控制箱和示教器、牢固底座 | 型号、序列号、固件、SDK、工具与用户坐标、工作空间、负载及重心；工具、转接板、传感器和线缆合计负载及力矩需满足本机约束 |
| 视觉 | 固定相机及受控照明，优先评估 RGB-D 或工业三维传感器 | 在真实金属和工作距离下测薄批缝分辨率、深度偏差、反光与缺失；必要时评估结构光或激光轮廓，不预先指定品牌即可达标 |
| 工装与工具 | 可靠夹具、小型主轴、合适磨料及耗材 | 防滑、装夹重复性、工具跳动、转速控制、启停信号、工具寿命、粉尘收集及飞屑防护 |
| 接触测量 | 兼容六维力传感器及适当柔顺机构 | 量程、带宽、安装刚性、负载补偿、通讯、零漂与振动；无合适力测量时先完成空跑 |
| 计算与记录 | 工控机或开发机、隔离的机器人网口、统一日志时钟 | 控制通信抖动、状态反馈、断线、错误码、命令时效与存储；VLA 算力作为独立后续配置 |
| 现场保护 | 急停、防护和现场联锁按实际风险配置 | 由现场责任人确认磨削工况下的保护与操作权限；协作机器人名称不能替代磨削现场措施 |

官方 [运动 SDK 文档](https://fairino-doc-en.readthedocs.io/latest/SDKManual/PythonRobotMovement.html)提供 MoveJ、MoveL、ServoJ、ServoCart 等接口；[力控 SDK 文档](https://fairino-doc-en.readthedocs.io/latest/SDKManual/PythonRobotForceControl.html)提供传感器配置、负载补偿、力保护与恒力控制。在线文档不保证现场固件支持同样参数，实施时锁定匹配版本。

第一阶段优先用控制器原生轨迹指令实现可记录的低速路径。MoveL 位姿通常使用 mm 和度，速度参数存在百分比与物理速度模式，必须逐项核对。若使用 ServoCart，其文档默认周期参数为 0.008 s；这不是本机已测实时能力。须实测循环延迟和丢包并验证异常停止，不能用 Python 循环加 sleep 推定满足实时控制。

## 标定与误差预算

以 `T_A_B` 表示把 B 系坐标变到 A 系的齐次矩阵。固定外置相机时，点位置为 `p_base = T_base_camera · p_camera`。手腕相机时为 `p_base = T_base_flange(q) · T_flange_camera · p_camera`。标定文件必须注明方向、长度单位、日期、硬件安装状态及坐标约定。

1. **相机内参与深度。**采集覆盖视野、距离和姿态的标定板图像，求内参及畸变；用独立量块或高度样件验证深度偏差与缺失。RGB 与深度配准必须单独检查；报告工作区域误差，不能只报重投影均值。
2. **手眼与外参。**固定相机求相机到基座；手腕相机求相机到法兰。采集约 20 至 30 个充分变化的机器人姿态作为初始工程建议，避免仅平移或绕单一轴。留出独立姿态及工作区验证点，检查矩阵方向和旋转定义。
3. **TCP 与工具。**以实际加工接触点定义 TCP，做位置与姿态标定，核验球形磨头半径、长度、跳动与安装偏心。不能直接沿用仿真名义 6 mm 磨头及 TCP；更换、磨损后重新检查。
4. **夹具与工件。**测夹具到基座、重复装夹和工件配准误差；在工件坐标中保存路径，记录每次配准变换。孔、筋及禁止加工面需实际标识。换型涉及不同夹具或新工艺时仍需验证。
5. **独立联合验证。**主轴关闭，使用测针或独立计量设备检查工作区至少 10 个未用于标定的三维点及法向。重复装夹不少于 3 次，报告位置和角度 P95、最大值及异常点。

误差预算须分别记录视觉、外参、TCP、装夹、机器人运动与工具变形。独立随机项可做平方和估算；共同偏差和相关项需保守叠加，不能只用机器人重复定位指标代表绝对加工误差。

**初步门槛建议：**联合位置误差 P95 ≤ 0.5 mm、最大值 ≤ 1.0 mm，TCP 重复核验误差 ≤ 0.3 mm，法向误差 P95 ≤ 3°，作为开始讨论轻接触的测量条件。这些值未获甲方确认；若缺陷及过切容差更小，应收紧。不能达到时只能进行适当加大间隙的空跑或调整传感器与工装。初次真机空跑建议 ≥ 5 mm 名义间隙，同时大于实测最坏误差、工具外形误差和运动滞后之和，并检查整段路径；正式仿真的 3 mm 间隙不直接迁移。

## 力控与真实去除试验

力传感器在装好全部末端负载后执行重力、重心与零点校准，检查多姿态残差。法向恒力、切向进给、最大调节位移及超力保护的方向要在无主轴静态接触中验证。优先采用兼容的控制器内置力控或经过验证的柔顺工具；研发期不以未经验证的上位机伺服替代接触稳定性验证。

接触顺序为无旋转工具静态触碰、短距离低速拖动、主轴开启的小样单道，再增加局部覆盖。每一步都有最大力、位移、时长和退刀条件；由工艺人员依据材料、磨料和主轴确定数值。初版不预设“通用最佳力”。停止触发后先停主轴/运动，再按现场确认的过程退刀；通讯恢复不自动接着磨。

在可报废样件上固定转速、进给、法向力、道次及磨料，记录实际去除量，再做小范围参数试验。每次只改变可识别的因素，比较残余高度、过切和表面质量。加工前后用独立三维测量或轮廓量仪建立共同坐标基准；仅比较两张光照不同的照片不能证明去除量。工具磨损和温升另行记录。

## 分阶段交付与门槛

| 阶段 | 工作与交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| G0 工件与现场确认 | 样本、尺寸与材质、正常结构和禁止面、验收量、设备版本、工具负载清单 | 夹持与工具方案确认，误差和质量目标可测量 |
| G1 测量和标定 | 内参、外参/手眼、TCP、工件配准、独立验证报告 | 联合误差符合工艺要求；错误变换和无效深度会阻止执行 |
| G2 主轴关闭空跑 | 自动拍照选区到低速完整路径、进退刀、状态反馈和异常停止录像 | 重复装夹后轨迹仍对齐；无未经允许接触、越界或失效继续；急停和断线过程符合现场确认 |
| G3 可报废小样接触 | 无旋转触碰、短道磨削、力曲线、前后计量、工艺窗口 | 接触稳定，无不可接受过切；残余和质量符合小样标准；各条件达到后再扩大区域 |
| G4 工件族验证 | 独立新工件/新批次、正常件与异常件、人工修正记录 | 双方锁定验收集；质量、干预率、节拍和异常恢复达到约定值 |
| G5 小规模现场试运行 | 班次记录、耗材、维护、日志留存与工艺版本 | 由甲方和现场责任人确认进入生产；单次 demo 不构成该门槛 |

G0 至 G3 的失败应保留记录并修复，不跳过后进入整件加工。G4 中应同时包含正常件、薄批缝、反光/遮挡、超工艺范围残留和装夹偏移；人工 ROI 修正单独统计，不混入自动成功数。

## 数据与验收建议

每次运行保存工件/批次、材质、装夹、标定和工艺版本，原始 RGB/深度/点云、有效像素、区域、人工修改、全部变换、带时间的 TCP 位姿、关节、主轴、六维力、命令和实测时间、停止原因。保存加工前后独立计量和质量判定，按工件划分训练与测试，避免同一工件重复拍照同时进入两组。

G1/G2 建议先准备约 10 至 20 件真实样本，每件至少重复装夹 3 次；G3 可先做 3 至 5 件可报废小样探索工艺。这些数量只用于可行性验证，不能证明量产缺陷率。验收应看自动选区漏检、正常结构误选、三维定位误差、预检拒绝、执行偏差、实际残余与过切、人工干预率及总周期。样本量、容差和合格率由甲方明确后写入验收协议。

总周期分开报告采集、检测、规划、确认、传输、转移、加工、复检及异常恢复；同时记录工程师调试工时。研发机器上的仿真时间和历史企业案例节拍不用于报价产能。

## 工程人天估计与假设

估计对象是一个固定夹具下、上表面可见的工件族，现成 FR5 和相机可用，小型工具与兼容力传感器可采购，现场有工艺与设备支持，SDK 正常开放，每人天约 8 小时。估计为开发工时，设备采购、制造等待、现场预约及额外合规工程不包含在内。

| 工作包 | 工程人天范围 |
| --- | ---: |
| 样本、验收、现场与接口确认 | 2–4 |
| 工装/工具方案及集成验证 | 4–7 |
| 相机、手眼/外参、TCP 与联合测量 | 4–6 |
| 真实视觉基线、路径及 FR5 接口适配 | 6–10 |
| 空跑、异常停止与记录联调 | 3–5 |
| 小样力控与工艺窗口探索 | 6–10 |
| 独立工件验证与文档交付 | 4–6 |
| **基础合计** | **29–48** |
| 适配返工预留，约基础工时的 20% | **6–10** |
| **初步总计** | **35–58** |

两位主要工程师配合现场人员，考虑依赖关系后可按约 4 至 7 个工作周讨论；不能用总人天除以人数直接承诺工期。若需要另行训练数据集、换传感器、做多面工装或自研实时力控，应重新估算。VLA 数据适配、影子评估和首轮微调另预留约 12 至 25 人天，GPU、数据规模和重复实验未明确，暂不把 VLA 达标列为基础工期条件。

主要待确认项：真实材质与缺陷尺寸、质量公差、工具与夹具、FR5 固件和力控支持、相机测量能力、样本可用性、现场节拍与甲方/团队分工。报告日期采用客户端的 2026 年 10 月 7 日，正式仿真结果及其适用边界见[项目研究](research.md)。
