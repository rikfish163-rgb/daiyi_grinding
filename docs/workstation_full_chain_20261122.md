# 097 底座整站打磨仿真闭环验证

验证日期为 2026 年 11 月 22 日。入口为本地 `http://127.0.0.1:8848/` 的 ESTUN 整站控制台。

## 改动与使用方式

- **观测与识别**。标准工况可使用训练好的专用分割网络，网络以 RGB-D 为输入并识别飞边和毛刺。组合模式将网络实例补到几何识别覆盖不到的位置，再按 CAD 表面与法向合并多视角候选。低矮薄批缝预设使用 CAD 深度差识别。两套预设都绑定 097 底座 CAD 和六视角观测。
- **防护与规划**。加工候选先经过保留区的磨具扫掠范围判断，再做整段运动预检。转场在完成离面后尝试直连，目标关节分支和全段预检通过才采用，否则走原转场。连续的同支路轨迹只在确切端点相接且通过预检时合并。控制台可切换原夹持和对侧夹持，仿真分别使用对应的工件位姿、夹具和碰撞模型。
- **复检与回磨**。首检把待处理区域绑定到 CAD 的表面锚点。磨后用实际可见的 RGB-D 深度重测这些同一位置，并记录视角、锚点覆盖、峰值与不确定度上界。未覆盖、上界过线或读数超差的区域进入复核。满足条件时可补拍一个预测可补齐观测的角度。自动回磨受在途防护、运动预检和加工轮次限制。
- **验收与追溯**。`cycle_receipt.json` 分别记录观测放行、仿真几何余量和运动门槛。每次保存 CAD 和配置来源、预检结果、逐段回放和多视角复检。`estun_path_preview.csv` 是仿真路径预览。运动门槛要求零非预期接触，轨迹跟踪和表面误差的 P95 均小于 1.0 mm。复检的 CAD 正余量上限为 0.30 mm，整件放行要求完成六视角及原登记区域验证。

## 实物验收接口

现场量测清单示例见 `config/site_acceptance.example.json`。CSV 字段按 `serial,zone,point_id,before_mm,after_mm,uncertainty_mm` 提供，磨前与磨后必须是同件、同一区域、同点位的独立测量。正负符号分别表示高于或低于名义 CAD 表面。`required_zones` 同时登记加工区及保护区。以 `sha256sum` 计算实际 CSV 的哈希，再写入清单。实测清单将 `source_kind` 填为 `real_measurement`。

```bash
python -m daiyi_grinding.workstation_delivery \
  --manifest /path/to/site_acceptance.json \
  --output /path/to/site_acceptance_result.json
```

程序按 `after_mm ± uncertainty_mm` 整个区间是否在双边公差内计分，出界点和缺失区域分别列出。现场尚缺同件磨前磨后独立量测、装夹重复定位、相机及 TCP 标定、磨具力控与去除标定、ESTUN 控制器试磨回执。当前交付可复现实验、定位失败并读取后续实测证据。
