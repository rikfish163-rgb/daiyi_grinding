# 小范围接触敏感性试验

本轮在同一段视觉识别批缝上运行约20mm路径，比较工具名义间隙与MuJoCo软接触参数。机器人用位置伺服，没有材料去除、旋转主轴或恒力闭环。试验说明接触效果依赖模型和标定，不能作为真机设力依据。

| 名义TCP间隙 mm | solref时间常数 s | 接触峰值 N | 接触积分步 2ms | trace RMS mm |
| ---: | ---: | ---: | ---: | ---: |
| +0.3 | 0.015 | 2.178 | 18 | 0.042 |
| +0.0 | 0.015 | 3.154 | 98 | 0.132 |
| -0.3 | 0.015 | 14.849 | 316 | 0.401 |
| -0.3 | 0.030 | 12.049 | 412 | 0.397 |

正间隙仍可能发生接触：工具有有限球面，路径经过平滑与离散采样，邻近表面也会参与接触。负间隙只表示位置指令深入不去除材料的接触模型，不能解释为实际切深。solref时间常数改变的是仿真约束响应；这些数值不是实测材料参数。

原始证据：[逐组摘要](../results/contact_probe/summary.json)，各trial目录保存逐10ms位姿CSV和每2ms聚合接触统计。没有非预期接触通过的声明替代允许工具接触计数；干运行的主demo另外要求工具接触为零。

复现（在/home/hts/demo1执行，输出目录须新建）：

```bash
MUJOCO_GL=egl .venv/bin/python -m daiyi_grinding.contact_probe --output daiyi_grinding/results/contact_new
```
