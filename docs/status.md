# 当前结果与推进方案

戴屹原型已串联 RGB-D 检测、自动/人工 ROI、轨迹和工具姿态、图像标定、FR5 MuJoCo 动力学与网页演示。正式证据采用 `demo_v3`、`benchmark_v3` 和 `vla/shadow_v1`。

2026-11-18 已完整重跑上述 FR5 基线，并完成多方法配对比较与现成 CAD
工件的缺陷造样实验。新结果和原始记录见
[本轮实验报告](defect_experiments_20261118.md)。原基线指标保留其原值。

| 新实验 | 留出或执行结果 | 适用条件 |
| --- | --- | --- |
| 原仿真复现 | 14 段、120.87 秒，原检测指标和轨迹一致 | 原 FR5 合成场景 |
| 鲁棒局部基面 | 薄批缝精确率 80.84%、召回 89.58%；同种子几何基线召回 29.02% | 无 CAD 参考的原工位；高噪声回退几何基线 |
| 候选轨迹执行 | mixed 133.112 秒、thin 31.556 秒，两次运动门槛通过 | 名义 3 mm 间隙，MuJoCo FR5 |
| 复杂 CAD 薄批缝 | 新参考法在 1920×1440 精确率 96.78%、召回 62.01% | 同姿态正常 CAD 参考；仍有漏检 |
| 公开飞边照片 | 已取得 8 对图像与标签并跑两种 RGB 方法 | 注塑塑料跨材质对照，未取得真实金属毛刺像素数据 |

CAD 模型 `097`、`021` 是文件版本标识，制造阶段未确认；新毛刺与批缝
由程序注入。复杂 CAD 上的单帧鲁棒局部方法存在明显正常表面误选，不能
直接使用原 FR5 选型结论。CAD 整站演示包含静态观测与轨迹预览，未将该
轨迹下发给 ESTUN 机械臂执行。材料去除、力控和真实加工质量仍未验证。

## 后续安排

| 顺序 | 工作 | 进入下一阶段的依据 |
| --- | --- | --- |
| 1 | 建立真实工件、相机和人工标注数据；薄批缝、正常筋与反光区域分别保存 | 独立样件上的检出与误加工区域结果 |
| 2 | 核对真实 FR5 版本、TCP、工件夹具、相机内外参与联合坐标 | 独立测量和留出点验证通过 |
| 3 | 主轴关闭，受控执行带间隙空跑 | 实际轨迹、夹具间隙、反馈和用户确认 |
| 4 | 受控小样试磨，建立力控与工艺窗口 | 接触力、去除量、过切和表面质量的实测记录 |
| 5 | 在现有数据盘恢复模型环境，准备 FR5 打磨适配数据与训练目标 | 可访问的模型环境、明确动作定义和可评价任务数据 |

真机步骤及门槛详见 [fr5_real_robot_plan.md](fr5_real_robot_plan.md)。工程维护优先保留可复现的几何基线，再推进真实样件和模型适配。

## 已知问题

当前仿真使用合成工件、理想针孔相机、简化惯性和碰撞代理。材料去除、恒力磨削、表面质量与真实反光金属泛化尚未验证；薄批缝漏检仍存在。

VLA 存在双臂到单臂、视图、坐标和工具映射缺口，尚未完成 FR5 打磨微调或任务成功验证。4090 的原模型环境和权重链接目标不可访问，恢复入口与双机操作见 [HANDOFF.md](../HANDOFF.md)。
