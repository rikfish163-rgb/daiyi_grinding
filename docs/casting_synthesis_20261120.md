## 形态依据与参数

依据 [杨国翱的飞边合成方案](../feishu_docs/飞边缺陷合成__wiki-LcFzw9XUoiiPGrkdFzTc9TT0n5e.md)
中的等弧长分型线、法向抬升、厚薄变化和断续，
以及 [工件样品照片与描述](../feishu_docs/工件样品概况__wiki-PgR0wKBsZitEVtk7LSzchUaKn5c.md)
中的卷曲、破裂、翘起和局部尖突。
借鉴 [AF3AD](https://arxiv.org/abs/2606.29181v1) 的局部坐标与参数化思想，
但薄片、断口和根部实体由本工程自行实现，没有声称运行了它的原代码。

参数在 [casting_synthesis.json](../config/casting_synthesis.json)。
下表为合成范围，不是从实物统计得到的概率分布。

| 网页选项 / CLI case | 生成的形态 | 主要范围 |
|---|---|---|
| 变厚弯曲批缝 / `casting_flash` | 沿 CAD 支持曲线连续生长，宽高具有空间相关变化，两侧逐渐回到本体 | 长 65–100 mm；高 0.55–2.6 mm；全宽 0.55–1.7 mm |
| 断续低矮飞边 / `casting_interrupted` | 三个有独立根部的片段，中间保留真实空隙 | 长 36–58 mm；高 0.35–1.7 mm；全宽 0.45–1.4 mm；间断约 1.5–4 mm |
| 卷曲薄片飞边 / `casting_curled` | 有上下两面和有限厚度；自由边弯向下方，形成遮挡 | 沿根长 38–60 mm；薄片弧长 4.2–6 mm；厚 0.22–0.65 mm |
| 破裂与缺口飞边 / `casting_torn` | 三段连接本体的薄片，外沿有不规则缺口，根部仍保留 | 沿根长 32–50 mm；薄片弧长初值 2–4.8 mm；厚 0.2–0.8 mm |
| 不规则局部毛刺 / `casting_burr` | 不对称、多峰的紧凑余料，分别放在上法兰和侧壁 | 名义足迹直径 4–8 mm；高 0.8–2.8 mm |
| 混合缺陷 / `casting_mixed` | 上法兰变厚批缝、卷曲与破裂薄片，侧壁断续飞边和毛刺 | 五个对象；侧壁根部长度限制在已支持的局部补丁中 |
| 正常铸件 / `casting_normal` | 无新增余料，保留 CAD 的孔口、筋、台阶和口沿 | 与同种子研究缺陷件共享灰色铸件材质 |

候选根部来自 CAD 上有支持的曲线和侧壁补丁，尚未获得模具分型线图。
不会把它们表述为公司的真实分型线。所有新增实体都有根部嵌入，
断开的片段仍连接本体，没有生成漂浮碎片。
卷曲薄片通过积分截面转角构造，具有正的内弯半径；
其表面不再只是单值的高度脊。

这一统计不能当作真实根部可测率。飞边中心根部常被余料本身挡住，
因此识别掩码与根部测量需分别处理。

## 数据结构与复现

每个 sample 文件夹中：

| 路径 | 用途 |
|---|---|
| `public/view_XX.npz` | 原始 RGB、带噪深度、正常参考深度、K、相机/工件/世界变换和编码器；不含标签 |
| `public/view_XX_rgb.png` | 未叠加语义颜色的相机 RGB |
| `evaluator/view_XX_labels.npz` | 像素语义/实例标签、完整三维根部、曲线偏移、根部投影及深度一致性 |
| `evaluator/object_XX.json` | 形态参数、基底与法向、根部、闭合候选去除带和几何验证 |
| `evaluator/*_macro.png` | 单独近景相机的缺陷/正常对照，仅供展示和检查 |
| `view_XX_paths.png`、`paths.json` | 原有几何算法的预测；与生成真值分别保存 |

语义标签：0 背景/其他设备，1 合成飞边，2 合成局部毛刺，
3 可见的正常 CAD。实例标签使同一飞边的破裂片段保持同一对象身份；
完整根部与片段偏移另行保存。去除带是合成监督，
不能绕过实际工艺许可或作为直接控制输入。

```bash
# 新目录生成全批次；既有结果不会被覆盖
.venv/bin/daiyi-casting-synthesis \
  --output runs/casting_synthesis_new --seeds 9301 9302

# 单独生成某形态的六视角样本
.venv/bin/daiyi-casting-synthesis \
  --output runs/curled_new --seeds 9401 --cases casting_curled

# 接入原识别与整站安全规划；本命令不执行打磨
.venv/bin/daiyi-workstation --case casting_mixed --seed 9301 \
  --views multi --tool belt --perception-only \
  --output runs/casting_workstation_new
```

同一实体种子的全部工况、角度、裁块、增强和前后状态必须进入同一数据划分。
本批可用于标注接口、专用分割的开发和几何/规划失败分析。
真实部署仍需实物采集与加工定义，以及真实材质、反光缺点、
标定误差和磨削过程的验证。
