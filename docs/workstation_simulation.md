## 对象与坐标

安装底座、机械臂、抓手、定位夹具、待加工铸件、附加缺陷、固定磨具、
砂带机本体、上料台、相机、转台和环境各有独立语义 ID。浏览器支持分别
点选、分色和显示/隐藏。

路径存于 `workpiece_097` 局部坐标，单位米。CSV 导出单位毫米。
抓手搬运工件时，根据完整的工件—抓手—世界刚体变换计算六轴姿态；
抓手是夹持器，固定磨具是加工工具。初始上料朝向为 180°，之后
转台分度扫描并回到整圈零相位；固定夹具不随转盘旋转。
现有工件—抓手数据关系按 STEP 导入坐标推导，真实夹持与手眼标定尚待替换。

砂带功能面为原始砂带机 CAD 背板前方 1 mm 层，中心
`[-1.2608838, -0.0024748, 1.1165946]` m，尺寸约 75 × 140 mm。
它有独立工具几何与接触语义。该功能层的厚度/工艺属性是配置值，
没有声称原 STEP 包含已标定的磨料参数。原磨轮位于整站另一工具工位，
选择 `--tool wheel` 可作对照。

砂带机曾使用三个大碰撞代理，包住了 CAD 空隙。当前用原 CAD 各独立实体，
对长实体分块后取凸包，保留它们原始位置。机械臂、抓手、工件等仍使用
CAD 派生碰撞体，因此几何验收有近似误差，不是实际控制器认证。
工件的第三版碰撞体按 CAD 的水平面分层、独立实体和上沿细网格划分，
避免一个凸包跨过底板与凸起边沿，产生不存在的薄层干涉。
碰撞代理清单位于 `collision_belt_v4` 和 `collision_workpiece_v3`。

## 可运行闭环

1. 固定相机在六个转台分度角采集带缺陷 RGB-D 和同姿态正常 CAD 参考深度。
2. 从观测差分测出正余料，保护参考边缘，保留窄批缝与缺陷 ROI 的全部有效点。
   小片正余料可按 CAD 坐标的 2 mm 距离连接，缺失像素不会变成新增材料。
3. 各视角按真实工件位姿回到同一工件坐标。融合局部检测，保持稳定区域编号，
   每一帧写入不可变的 `predictions/revision_*.json`，实时更新路径。
4. 将观测点与同像素参考点之差投影到参考表面法线，以正余量的 80% 分位数
   估计法向高度。只有批缝/毛刺的该估计超过 0.3 mm 才生成加工路径。
   光轴深度差与法向余量分别记录；较弱信号仍保留作识别评分。
   运行曹正恒原 CPU 物理轨迹滤波，再约束到参考表面和允许加工范围。
5. 各路径段独立搜索工件姿态和磨具接触点；检查完整携件几何、进出段和
   段间连接。直接连接失败时运行有限时间/节点的 RRT。失败候选回滚；
   完整命令曲线预检失败时，整条命令不会执行。单姿态与分段规划共用
   60 mm 法向退让，退让终点及连接仍须通过原关节限位、携件碰撞和曲线检查。
6. 通过验收的路径采用 C1 关节曲线。预检与实际伺服使用同一曲线。
   MuJoCo 连续积分关节和自由工件，夹持/释放由约束切换完成。
   速度与逆动力学加速度前馈施加到六个机械臂自由度，并计入持件载荷；
   自由工件重力保留。夹持约束按高刚度近似，尚无真实夹持柔度标定。
7. 仅由实际工件位姿和磨具扫掠更新生成余料的顶点。正常 CAD 网格不修改。
   设置 `--removal-rate-mm-s` 时，再以法向去除率和足迹内积分时长限制去除量，
   转运与未接触时间不计入去除；未配置时保留原几何扫掠。
8. 回到上料位置，重新执行六视角扫描，重算法向余量、待加工区域与路径。
   按观测余量、实际运动安全门、候选路径和轮数预算决定补磨或停止，
   保存 `controller_stopping`。`--max-passes 2` 表示总共最多两轮执行，
   包括首次加工。
   重复确认的正超差锚点可选取此前许可轨迹的局部子段，同轮去除重复路径。
   有名义去除率时，局部进给按观测上界和原许可材料余量安排足够轨迹时间。

真值在检测与路径预测返回之后读取，只用于评价。生成器的缺陷中心、
标签、原始顶点和材料余量没有作为检测器或规划器输入。
`goal_complete` 也是评测结果，不参与补磨/停止分支。
正常 CAD 参考与精确位姿是当前方法的前提，需要真实标定才能转为实测。

## 怎样使用

```bash
# 浏览器：默认当前 ESTUN 工位。
MUJOCO_GL=egl .venv/bin/daiyi-serve --port 8848

# 观测、实时预测、逐段规划和原局部规划对照。
MUJOCO_GL=egl .venv/bin/daiyi-workstation \
  --case mixed --seed 7007 --views multi --tool belt \
  --perception-only --compare-planners --output runs/current_plan_new

# 完整抓取、携件加工、复检；总共最多两轮执行。
MUJOCO_GL=egl .venv/bin/daiyi-workstation \
  --case mixed --seed 7007 --views multi --tool belt \
  --max-passes 2 --realtime-factor 0 --output runs/current_execute_new

# 冻结参数后，独立种子在完全相同观测上比较规划器。
MUJOCO_GL=egl .venv/bin/daiyi-workstation-benchmark \
  --seeds 9201,9202 --development-seeds 7007,9101,9102 \
  --output runs/current_holdout_new

# CLI 运行后，为浏览器导出保留全部反馈帧的紧凑回放。
.venv/bin/python -m daiyi_grinding.workstation_replay runs/current_execute_new
```

输出目录必须使用新名字。网页从“更新观测与预测”开始，自动选择可处理区域；
可以画零度图像 ROI，再重新预测，最后运行仿真。ROI 绑定到该帧可见的同一
三维表面，其他分度角不会把后面的隐藏表面误当作获得了加工许可。
ROI 需要容纳完整工具包络，太小的范围会不产生可执行路径。
开发与调试已使用 7007、9101、9102；本次最终独立验证使用 9201、9202。
后续修改算法后，应选择此前未用于调试的新种子并更新开发种子清单，
已看过的独立结果只能作回归验证。

## 评价与产物

每次运行包含 `result.json`、源码快照/哈希、`scene.xml`、三维模型导出、
逐帧 RGB-D/真值/相机变换、预测版本、逐段验收、工件路径 CSV、
关节命令、实际执行 CSV、真实积分状态回放与复检文件。
网页发起的运行完成后自动导出 `replay_compact.json`，相同余料状态只存一份。
全部原始反馈帧、位姿和数值保留，通过每帧的快照编号恢复该时刻余料，
跳过显示帧也不会漏掉材料更新。原始 `replay.json` 和执行 CSV 保留。
回放开始恢复初始余料，结束后恢复最终复检状态。

识别报告 TP/FP/FN/TN、Precision、Recall、F1、IoU，同时报告
检出/可见/全部生成的缺陷对象数。总体像素 Accuracy 正常像素占比很高，
不能替代缺陷指标。六帧是同一次工况的重复观测，不是六次独立实验。
规划统计完整验收段数/全部观测路径段数。动力学工况另外报告实际跟踪误差
和非预期接触。加工点误差由实际工件参考点与期望关节曲线 FK 的同一点
比较，包含抓手姿态和夹持偏转；不能用抓手原点误差替代。
只有生成路径或进程退出，均不能认定加工完成。

`goal_complete` 必须同时满足实际运动门槛、所有初始缺陷已观察并检出、
全工件余料峰值不高于 0.3 mm。其余运行明确显示部分完成或受阻。
当前运动门槛为抓手和加工点误差 P95 均小于 1 mm、非预期接触为零；
这不代表已经达到 ±0.1 mm 的定位目标。
缺陷去除是余料顶点的几何扫掠模型，覆盖率是顶点口径；
没有标定恒力、材料去除速率、温度、粗糙度或表面一致性。
真实机械臂不会被此网页或 CLI 驱动。
有限率样例的名义规划率与仿真 plant 率相同，只验证声明工艺假设下的闭环行为；
实际材料、力、磨耗、温升与表面质量仍需独立标定。可重复的两轮加工结果见
[功能样例](functional_grinding_20261123.md)。
