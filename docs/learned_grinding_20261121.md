# 人造 097 数据训练与自主打磨闭环

2026-11-21 已训练并接入专用 RGB-D 分割模型，实际执行了当前 ESTUN
iER220-2700 携件砂带打磨。模型负责识别飞边、毛刺和保留区域；路径从观测的
三维几何中生成，再经过六轴逆解、携件碰撞、进出段和整条连续曲线检查。
本轮没有训练直接输出关节命令的网络。

**已实现的去除证据**：当前 097 基准毛刺工况中，4 段自动路径全部通过检查并
执行，3 处生成毛刺的几何峰值从 2.732 mm 降至 0.236 mm，异常接触为 0。
两处毛刺被网络归入飞边类别，初始对象匹配仅 1/3，因此完整任务仍保留
`goal_complete=false`。界面显示“余量达标 · 识别待复核”，没有放宽原验收门槛。

这些结果来自合成工件及几何余料去除仿真。杨的真实 097 点云尚未取得；
相机、装夹、材料去除率、力控、热和表面质量均未经过实测标定。

## 实际训练的网络

- `DefectUNet`，387,683 个参数，随机初始化，无预训练权重。
- 3 类：背景/保留结构、飞边、局部毛刺。
- 11 通道：RGB、配准深度差、局部深度差中值与离散程度、正常 CAD 法向绝对分量、
  正常深度和测量有效性。
- 全分辨率 256×256 裁剪，1,358 个训练块；同时包含正常样本、全图网格和困难负例。
  推理采用重叠裁剪覆盖完整 1024×768 图像，不由原几何检测区域限制搜索范围。
- 加权交叉熵与前景 Dice；AdamW、学习率 0.001、权重衰减 0.01、
  余弦学习率、梯度裁剪 1、batch size 8。
- RTX 3070、PyTorch 2.6.0+cu124；训练采用 bf16。共 1,200 步，
  包含验证的训练阶段约 153.4 秒。

正式训练前的[单批优化检查](../runs/learned_grinding_20261121/training_01/one_batch_check.json)
将 loss 从 2.023 降至 1.079。第 400、800、1,200 步均用完整验证视角评价。
选择依据为两种缺陷类别的宏平均 F1，并惩罚正常样本误报；因此最终保留
第 800 步、概率阈值 0.35，而不是最后一步。

选定验证指标：前景 F1 **94.89%**，类别宏平均 F1 **85.08%**，正常样本误报 0。
记录在[验证选择结果](../runs/learned_grinding_20261121/training_01/selected_validation.json)。

## 独立测试与同输入对照

以下前景指标统计“是否为缺陷”，与类别正确的逐类指标分开。
网络原始分割包括细小、边缘及缺失深度位置；进入工站的可测候选额外需要
有效深度、正常 CAD 可见表面、边缘保护和正深度差。
生成加工路径还要求观测的法向余量超过 0.3 mm。

| 同一批 84 帧测试 | 前景 Precision | 前景 Recall | 前景 F1 | 前景 IoU |
|---|---:|---:|---:|---:|
| 原几何规则的飞边/毛刺候选 | 99.37% | 36.60% | 53.50% | 36.52% |
| 学习模型原始分割 | 93.99% | 94.02% | 94.01% | 88.69% |
| 学习模型经过可测表面约束 | 98.58% | 86.09% | 91.91% | 85.04% |

原几何与学习候选使用相同 RGB-D、正常 CAD、位姿、有效深度和 CAD 边缘保护。
原规则另有 6,719 个像素被归为“待复核”，这些没有被冒充为未检测到的材料；
上述表格统计它能直接给出飞边/毛刺类别的候选。原规则有部分飞边被归入毛刺，
所以逐类指标较前景指标更低。正常对照中两者的误报均为 0。

网络原始分割的飞边 F1 为 **94.25%**，毛刺 F1 为 **62.77%**，
毛刺 Recall 为 **46.99%**，类别宏平均 F1 为 **78.51%**。
经过可测表面约束后，毛刺 Recall 降至 **38.80%**。这说明当前小目标识别和
固定相机采样仍是短板，整体前景高分不能代表所有毛刺都能被加工。

## 模型如何变成机械臂运动

1. 固定相机在转台实测编码器角度下采集六帧 RGB-D。
2. 冻结 U-Net 独立扫描完整图像，给出飞边/毛刺概率和像素区域。
3. 正常 CAD 深度、测量深度、法向和许可表面将区域转成可测的三维余料。
   无有效三维观测的位置可以形成视觉线索，不能直接授权加工。
4. 当前几何路径算法提取有序局部接触参考，复用曹原始 CPU 滤波代码，
   再投影回观测的正常 CAD 表面。这里的路径不是经过真实标注验证的精确缺陷根部。
5. 逐段搜索工件姿态和砂带接触点，验证六轴可达性、工件/抓手/机械臂碰撞，
   对转场进行有界避障修复，最后验证整条 C1 曲线。
6. MuJoCo 连续积分位置伺服、速度和逆动力学前馈；实际机械臂夹持工件送到固定砂带。
   执行过程没有瞬移关节或工件。余料裁切由实际工件位姿触发。
7. 返回转台后重新拍摄，用同一模型复检。测量余量、运动验收和轮数决定是否补磨，
   评价真值仅在结果评分时使用。

模型权重和输入版本的哈希随计划保存。网页改变识别方式、工况或 ROI 后，
原计划不可继续提交执行；权重或整站模型变化同样要求重新观测和规划。

### 团队先验的复杂混合缺陷

[mixed_9301_closed_loop_01](../runs/learned_grinding_20261121/mixed_9301_closed_loop_01/result.json)
使用团队先验和新模型。11 段候选中 3 段通过并执行，
外侧断续飞边被几何去除，但整体峰值仍为 5.303 mm，
4 个区域超过 0.3 mm。实际加工点误差 P95 为 1.437 mm，
抓手 P95 为 1.117 mm，均超出当前运动验收线；异常接触为 0。
本轮结束后的验收拒绝了继续补磨。它不是一次完全成功的复杂铸件打磨。

[interrupted_9501_closed_loop_01](../runs/learned_grinding_20261121/interrupted_9501_closed_loop_01/result.json)
生成 3 条候选，但全部因携件姿态干涉被拒绝，机械臂没有执行。
顶面加工涉及工件凸起、抓手及砂带设备的实际干涉；
增加砂带边缘接触候选的开发诊断也没有得到该工况的无碰撞姿态。
模型能看到材料不代表当前装夹和磨具能够触达它。

## 使用与复现

网页：<http://127.0.0.1:8848/>。选择“专用 RGB-D 分割模型”，可更新观测，
自动规划并运行当前 ESTUN 仿真。“原几何规则”保留为对照。
已完成记录可以回放实际反馈及余料网格变化。

运行当前基准毛刺闭环的复现命令如下，使用新目录避免覆盖证据：

```bash
MUJOCO_GL=egl .venv/bin/daiyi-workstation \
  --seed 9101 --case burr --detector learned \
  --checkpoint runs/learned_grinding_20261121/training_01/model.pt \
  --views multi --tool belt --max-passes 2 --realtime-factor 0 \
  --output runs/learned_grinding_20261121/burr_9101_reproduction
```

团队形态工况另加 `--case casting_mixed --casting-profile team_prior_20261121`。
CLI 默认仍保留原几何检测，学习模型须显式选择并提供权重。

训练复现：

```bash
.venv/bin/daiyi-defect-model train \
  --batch runs/data_reuse_20261121/team_prior_batch_final_02 \
  --batch runs/learned_grinding_20261121/synthetic_extension_01 \
  --split-plan runs/learned_grinding_20261121/split_plan.json \
  --chip-cache runs/learned_grinding_20261121/chips_01 \
  --output runs/learned_grinding_20261121/training_reproduction \
  --steps 1200 --validate-every 400 --batch-size 8
```

原冻结模型评价、候选对照和图表重建入口分别为
`daiyi-defect-model evaluate`、`scripts/compare_learned_detector.py`、
`scripts/plot_learned_grinding.py`。重复评价不能用于修改这次冻结测试的选模结果。
