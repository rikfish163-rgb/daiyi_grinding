# 戴屹视觉打磨仿真实验计划

本轮交付相机驱动的 MuJoCo 原型、实验记录、甲方演示材料和 FR5 初步真机计划。默认自动选区，人工选区作为可用接口保留。仿真结论限定于观测、规划和运动执行，不将动画或覆盖率作为材料去除质量证明。

1. 调研需求、公司案例、工业打磨及 2026 年 VLA 工作，确定首版工艺边界。
2. 建立不等高、不等宽、带断续和粗糙度的铸件表面、批缝、局部毛刺及正常结构。尺寸是实验假设，待真实扫描替换。
3. RGB 和深度观测独立导出；检测器只接收观测与标定参数。生成标签只用于评分和监督训练。
4. 比较简单高度阈值与局部几何方法，测试噪声、薄毛刺、正常工件和超范围残留；保存失败记录。
5. 从检测区域生成带姿态、进退刀和工艺元数据的轨迹，验证 FR5 可达性和仿真跟踪。人工矩形/多边形 ROI 接入同一规划流程。
6. 核实最新 VLA 的可用性与动作定义，保留候选策略接口和实验，不把不适配的双臂权重当作 FR5 成品控制器。
7. 输出演示视频、可操作的本地演示、研究报告、复现命令、FR5 真机分阶段门槛。

首版采用机器人持小型工具、夹具固定工件、可见上表面批缝与局部毛刺。大型浇冒口切除、深腔、侧面倒扣、实际磨削去除量不纳入首版达成项。此选择是研发范围设定，不能替代甲方工件确认。

研究、程序生成工件、RGB-D检测、图像手眼标定、自动路径与姿态、FR5 MuJoCo执行、人工ROI与区域选择、VLA真实影子推理、接触敏感性试验、84条正式配对记录、4页甲方PDF、视频和带源码离线包均已生成。正式入口见README，验证汇总为results/verification/delivery.json。
