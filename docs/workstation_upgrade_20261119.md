# 2026-11-19 组会基础上的当前工位提升

更新：2026-11-20。本报告以最终冻结版本及新种子验证为主，
先前调试与失败记录保留在各自独立目录。

主入口已转为当前 ESTUN 工位：公司 CAD 的机械臂、安装底座、抓手、
定位夹具、097 工件、固定砂带、相机和分度转台。工况与操作见
`docs/workstation_simulation.md`，来源入口为 `INDEX_LOCAL.md`。

## 借鉴了什么

王释钰 11/19 的进展提供了最新 CAD 布置、机械臂携件加工工况和逐段
“筛选—原因分析—局部修复—完整验收”的路线。其四种工件、75 段、
11 段完整通过（14.7%）是组会报告成绩；源代码和相同四种测试工件的
全部数据未在已检索材料中完整提供。因此这里复现策略与新工况，
不声称运行了他的原实现，也不将自己的不同工件成绩与 14.7% 作成对比较。

曹正恒的公开仓库为 `https://github.com/CharlesH777/WeldGrind-V1`，
固定提交 `0e110bf14952cf89ef127342d6a10932d151fa62`，
本地源码在 `external/WeldGrind-V1`。
本工程实际导入并运行其 CPU 轨迹物理滤波，记录原模块哈希与提交。
其“观测/分割 → 三维 ROI → 路径 → 几何后处理”流程接入当前工件坐标
和安全门。公开仓库缺 SAM 与训练动作权重，未声称复现训练好的网络。
11/12 文档中的 14.91M 是参数量，95.42% 是运动阶段预测准确率，
并非缺陷识别准确率。

## 实质改动

| 原问题 | 当前落地处理 | 可检查证据 |
|---|---|---|
| 沿用旧 FR5 或把抓手当磨具 | 默认 ESTUN 全站与固定砂带，抓手携件；各部件分色/点选 | `components.json`、`model.json`、`scene.xml` |
| 手工多视角没有角度初值 | 固定相机 + 实际转盘伺服角度，直接统一局部坐标 | 各 `view_*_observation.npz` 和变换矩阵 |
| 等整云 ICP，薄缺陷被稀疏化 | 分度局部检测即发布路径；ROI 保留全点，背景只作有限采样 | `predictions/revision_*.json`、滤波报告 |
| 单一姿态导致整条路径失败 | 逐段法向、磨具接触点与腕部姿态搜索；连接段 RRT | `preflight.json` 逐段原因与修复次数 |
| 砂带代理包住空隙 | 依原 CAD 实体重建分块凸代理，设备位置保留 | `assets/ier220_workstation/collision_belt_v4/manifest.json` |
| 工件凸包跨过底板和凸起边沿，产生假干涉 | 按水平面、连通实体和细网格分解，剔除退化凸包 | `assets/ier220_workstation/collision_workpiece_v3/manifest.json` |
| 检查轨迹与执行曲线不同 | 预检/执行共用 C1 曲线，误差参考为同曲线 FK | 实际 `execution.csv`、跟踪参考字段 |
| 持件加减速有跟踪偏差，抓手误差不能代表加工点 | 加入六轴及持件载荷逆动力学前馈，分别测抓手、实际加工点和夹持偏转 | 每轮 execution 与原始 CSV |
| 仅动画，没有执行/材料反馈 | 六轴连续积分、夹持约束、实际磨具扫掠余料、复检和补磨 | 每轮 execution、rescan、final_stock、replay |
| 回放重复存网格，浏览器需读取接近 1 GB | 保留每帧真实状态，余料快照按编号共享；逐帧核验恢复结果 | `replay_compact.json`、`replay_equivalence.json` |
| 斜视角深度差被当作余料高度，停止依赖评测真值 | 法向余量决定加工资格；按观测、安全门和轮数预算决定补磨/停止 | `normal_height_mm`、`machining_required`、`controller_stopping` |
| 总 Accuracy 掩盖漏检 | 像素 F1/IoU + 对象检出 + 观测覆盖 + 完整段率分开统计 | `perception_metrics.json`、独立验证报告 |

开发与调试已使用 7007、9101、9102。最终版本冻结后，首次使用
9201、9202，覆盖 mixed、seam、burr、thin、normal、coarse 和 noisy。

源码、配置和独立种子协议在运行开始时保存，并在每次工况前复核。

`runs/workstation_upgrade_20261119/holdout_final_9201_9202/report.md` 与
`benchmark.json`。动力学闭环使用另外的独立目录，保留之前失败或中间

## 已完成的独立验证

最终冻结版本在 14 次工况（7 类 × 2 个新种子）中得到：

| 指标 | 结果 |
|---|---:|
| 可见缺陷像素 Precision | 99.02% |
| 可见缺陷像素 Recall | 82.61% |
| 可见缺陷像素 F1 / IoU | 90.08% / 81.94% |
| 检出 / 全部生成缺陷对象 | 34 / 34 |
| 检出 / 可见缺陷对象 | 34 / 34 |
| 完整几何验收路径段 | 47 / 63（74.60%） |
| 同观测原局部单姿态规划验收 | 9 / 63（14.29%） |
| 正常工件误报像素 / 自动加工路径 | 0 / 0 |
| 已验收计划的预检非预期接触 | 0 |

84 帧属于上述 14 个工况；只有 097 一种 CAD，不能声称测试了 14 种
不同零件。原局部规划指本工程之前的单姿态实现，不是王释钰原实现。
这些是识别与几何规划成绩，动力学执行分开核验。
对象检出只要求某视角的预测与该对象达到评价中的重合条件，
34/34 不代表每个对象的所有缺陷像素或整条加工面均已恢复。
噪声工况的像素 F1 为 77.08%、73.34%，仍是明显的薄弱项。

## 当前边界与后续方向

当前仅覆盖一种真实 CAD 的多种合成余料工况。侧壁有视线遮挡与碎片信号，
大抓手与宽砂带面也限制部分曲面可达性；系统须报告漏检、未观察和受阻段。
后续应针对失败证据增加工件呈现姿态/夹持方案，接入真实点云和已标定磨具，
再做完整覆盖与加工质量验证。

真实相机外参、转台轴线/编码器标定、抓手工件定位、砂带材料与转速/力控
参数仍未齐备。±0.1 mm 缺陷定位、±0.3 mm 表面一致性和 30 min
换型来自愿景指标，尚不能作为本次实测成绩。当前模拟余料峰值阈值
不等于真实加工后的表面质量。
