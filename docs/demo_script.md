# 戴屹视觉选区与 FR5 仿真五分钟演示脚本

演示的核心是：从相机观测自动选出批缝和局部毛刺，生成带工具姿态与进退刀的轨迹，通过可达性及碰撞预检查后，在 MuJoCo 中连续执行。人工 ROI 是可用备选，正常工件与失败案例必须展示。工件为程序生成，主流程是名义 3 mm 间隙空跑；材料去除和表面质量留给真机小样验证。报告日期采用客户端的 2026 年 10 月 7 日。

## 演示前准备

在 `/home/hts/demo1` 激活现有 Python 环境。正式示范使用 [demo_v3](../results/demo_v3/result.json)，seed 7、mixed、估计标定外参、0.06 mm 深度噪声及 0.3% 缺失，视频约 121 s。现场使用明确标注的结果回放和可操作界面；新运行必须选择空目录，避免覆盖原证据。

```bash
source .venv/bin/activate
python -m daiyi_grinding.run --output daiyi_grinding/results/demo_reproduce --video
python -m daiyi_grinding.benchmark --output daiyi_grinding/results/benchmark_reproduce --seeds 6 --seed-start 3007
python -m daiyi_grinding.serve --port 8848
```

本地界面打开 [127.0.0.1:8848](http://127.0.0.1:8848)。初始页面显示保存的演示记录，不代表已重新采集。点击“重新拍照与规划”产生新观测；自动可处理区域默认选中，保留结构与待复核区域不能提交执行。矩形 ROI 按住拖动，多边形逐点点击后选择“完成多边形”；修改场景或 ROI 后先重新规划，再点击“验证并仿真执行”。清除选区恢复全图自动检查，过窄 ROI 可能没有能容纳工具的路径。

正式演示前核对结果文件的生成时间和参数、预检查结论、视频与 JSON 是否对应同一次运行。预检查失败时展示拒绝与原因，不能把其它成功运行视频冒充该运行结果。将 mixed、normal、thin、noisy、coarse 的观测与逐场景记录准备好；人工矩形或多边形 ROI 使用同一画面及同一规划接口。任何指标只从该次结果读取。

## 五分钟顺序与讲解

| 时间 | 屏幕与操作 | 建议讲解 |
| --- | --- | --- |
| 0:00–0:35 | FR5、固定夹具和生成铸件全景；随后切到检查相机 | “这次先处理可见上表面的批缝与局部毛刺。工件是带粗糙度与正常结构的合成试件，后续会替换为贵方扫描和真实小样。” |
| 0:35–1:20 | RGB、深度、自动检测叠加；区分批缝、毛刺、保留和复核区域 | “默认不画框，检测模块只接收图像、深度和标定。它尝试选出多余材料，同时保护正常筋和凸台。细薄缺陷和复杂正常结构仍可能判断错误。” |
| 1:20–2:05 | 轨迹叠加、工具姿态、进退刀及工艺元数据；查看预检查结果 | “三维观测变成机器人坐标下的路径，包含姿态、转移和进退刀。预检查不通过就拒绝执行。这些工艺参数目前是实验设定。” |
| 2:05–3:00 | 仿真视频的沿轨迹片段和执行记录；可拖动跳过转移 | “机械臂在 MuJoCo 连续推进动力学执行，主路径沿表面保持名义 3 mm 间隙。该次沿轨迹误差 RMS 约 0.031 mm，每 2 ms 检查的工具接触计数为零。运动成功不代表已经磨掉材料。” |
| 3:00–3:35 | 人工矩形或多边形 ROI 限定一个目标，重新检测/规划 | “工程师可以限制检查区域；之后仍走相同的观测和规划链路。人工 ROI 不是指定真值，也不让有问题的深度或不可达轨迹通过。” |
| 3:35–4:25 | normal 阴性案例，再切 thin 和 coarse 的正式批测记录 | “新种子正常件 6/6 没有加工区域或复核提示。薄批缝召回约 28%，漏检尚未解决；超范围残留 6/6 已拦截为复核。我们保留这些失败和限制。” |
| 4:25–5:00 | 展示正式结果入口及真机阶段图表 | “下一步用真实工件验证测量和 TCP，主轴关闭空跑，再做可报废小样轻接触。残余、过切和质量达标后，才扩大加工范围。” |

视频剪辑可以压缩长转移和等待，但须标明回放倍速；计算耗时、仿真物理时间与真实预计节拍分开讲。若模型尚未通过预检查，现场演示止于选区和规划并解释失败，不能宣称全流程已完成。

## 必须能回答的三个问题

**是否自动发现区域？**默认检测输入来自 RGB-D 和标定，未读取生成缺陷标签。标签只用于评分。当前是针对已配置检查体积及工件上表面的几何基线，不具备任意工件识别保证；人工 ROI 可以缩小关注范围。

**是否真的能磨掉毛刺？**本次主流程为空跑，仿真未建立真实去除和表面质量模型。工具轨迹在缺陷 XY 投影附近的覆盖率只是几何覆盖。小范围接触结果只能作为模型接触研究，实际工艺需真实小样前后计量。

**是否用了 2026 年 VLA？**已实际运行 Hy-VLA 发布权重做本场景影子检查，6 组候选全部拒绝执行，执行动作 0 条；原始输出和阻断原因见[实验报告](vla_experiment.md)。这说明发布动作与单臂 FR5 磨削之间的适配缺口仍需处理。当前主演示使用几何路线，不能把它的执行归为 VLA 成功。π0.7 仅作同期研究背景，本轮未运行其模型。

## 建议的首版验收口径

这些是双方讨论用的验收建议，不是已签合同或已完成指标。

1. 自动默认从相机观测生成目标区域；人工 ROI 可复现，人工修正单独记账。
2. 在锁定场景和随机种子列表上报告识别与正常结构误选，保留薄缺陷、噪声和超范围失败。
3. 路径有单位、坐标系、工具姿态、进退刀和工艺元数据；可达性或碰撞预检查失败会阻止仿真执行。
4. 正式运行输出连续执行日志和 TCP 跟踪结果，视频、图像、轨迹与日志可对应同一次运行。
5. 实际去除量、残余、过切、粗糙度、节拍和工具寿命以真实小样及后续工件族试验单独验收。
