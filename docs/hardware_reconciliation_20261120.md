## 完成型号一致性验收还需的输入

1. 确认相机实机型号、序列号及对应 SDK/Viewer 版本，消除 S2-C 与 S1-M 的记录差异。
2. 获取所确认型号的内参、RGB/深度对应关系、外参和距离相关误差，调整仿真的工作距离及观测规格。
3. 确认工件转台、控制卡、伺服驱动器和编码器的型号，获取转盘尺寸、承载、减速比、角度分辨率及运动限制。
4. 用转轴、零位和角度重复性标定结果替换当前转台参数，做同一工件的实采与仿真对照。

本次仅补充核对记录，未修改冻结的算法配置、历史运行记录或独立验证结果。
现有识别率和闭环示例仍应表述为当前虚拟观测条件下的结果。
